## 约定

- **编号**：数字是 `问题记录.md` 的行号。插入新行后行号会变，引用前先重新查一次。
- **规模**：
  - 「小 PR」：在聊天里给出简短方案，确认后直接做。
  - 「需方案」：先写设计（`docs/superpowers/specs/`），再写计划，最后实现。
- **小问题**：各 PR 终审时没修的小问题记在 [backlog.md](backlog.md)。修掉一条删一条。
- **维护**：每合并一个 PR，就把对应行移到「已完成」；问题记录有新条目时，先排进本文件，再开工。

  - **定下的方案**：
    - 身价 = 近 7 天日均结算银币 × 5 × 热度。热度从 1.0 起，每被收购一次 +0.2，每天往 1.0 回落 10%，最高 3.0（身价反映店值多少钱，不会无限涨）。

    - 限制：每人最多拥有 10 家；被收购期间不能收购别人；每家店每天最多被收购 3 次；同一对店 7 天内不能互相收购；同 IP / 设备的号之间不能收购，进可疑数据；2 星以下不能被收购；一个老板每天的分红合计不超过自己近 7 天日均收入的 25%。
