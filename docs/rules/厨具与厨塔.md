# 厨具与厨塔

本文说明厨具强化数值和厨塔守塔人的规则。对应代码：
- `packages/config/data/game/equip_lore.json` 的 `stressTables`（强化数值表、穿戴等级）
- `packages/config/data/game/tower_fix.json`（守塔人第 5、6 层互换的名字、称号、台词）
- `packages/config/data/game/tower_elders.json`（赛厨长老的装备和加点，`pnpm -F @dt/server elders` 生成）
- `apps/server/src/modules/equip/`、`apps/server/src/modules/tower/`

## 1. 强化

- 每件厨具可以强化到 +10。
- 每次强化成功，这件厨具的属性总和（不含宝石）升到数值表里的下一档。
- 多出来的属性加在哪一项是随机的：按部位的属性顺序，每项 50% 的机会选中，都没选中就加在最后一项。
- 两档数值相同时，这次强化不加属性，但照样算成功，等级照样 +1。
- 用强化石必定成功，加的属性和不用强化石一样。
- 强化回退：按强化记录，一级一级扣回当时加的属性。
- 厨具详情页会写明"成功后属性总和 +N（到 M）"。

- 固定属性的厨具（比如阿卡玛之铲只加厨艺）：按原来各项的比例分。

## 3. 守塔人（赛厨长老，问题记录 408）

每层长老穿这一层的全套厨具、按等级加满属性点；加点和玩家一样只加厨艺、刀工、火候，厨具基础属性按正常随机的期望，强化增量（每级整份加到一项）和加点按模拟出的最难打分配。数据在 `packages/config/data/game/tower_elders.json`，由 `pnpm -F @dt/server elders` 生成（改等级、厨具、强化在 `apps/server/src/sim/elders.ts` 的 `ELDER_SPECS`），构建时校验它和厨具配置对得上。
