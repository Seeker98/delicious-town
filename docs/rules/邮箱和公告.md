# 邮箱和公告

本文说明邮箱、公告、赞助帽子的规则。对应代码：`apps/server/src/modules/mail/`、`announce/`、`equip/hats.ts`、`ops/scan.ts`；数值在 `tuning.mail`。

## 1. 邮箱

- 顶栏的信封显示未读封数，点开进邮箱。
- 邮件有三种收件范围：
  - **单店**：只发给某一家店。
  - **区服**：发给某个区服。
  - **全部区服**：发给所有区服。
- **全服邮件只给发送那一刻已经开着的店**，之后开的店看不到，也领不了。这是为了防止开小号反复领补偿。
- 有的邮件带等级门槛：等级不够时能看到，但领不了，会写明要几级。门槛按领取时的等级算，30 天内升够了就能领。
- 邮件发出 **30 天后过期**，过期后看不到，没领的附件作废。
- 附件领取后直接进仓库、橱柜：
  - 橱柜满了，食材进冰箱；
  - 仓库超过持有上限的部分会丢弃，并在个人日志里记一笔。
- "一键领取"会把能领的都领了。某一封出错不影响其他，出错的那封留着，稍后再领。
- 附件领完的邮件、本来就没有附件的邮件可以删除。删除只影响自己。
- 运营撤回的邮件，没领的人就看不到了，已经领了的不追回。

## 2. 公告

- 首页顶部显示最新一条公告，点开能看全部。
- 标了"重要"的公告，每个账号第一次进游戏时弹窗一次，关掉就算看过。同一账号在不同区服也只弹一次。
- 登录页显示发给全部区服的公告，比如停服维护通知。
- 公告只在设定的时间段内显示。

## 3. 赞助帽子

- 感谢对小镇作出贡献的餐厅，由运营通过邮件附件发放，不会掉落，也买不到。
- 发放时可以给这一顶帽子起名字（1~8 个字），显示为"玉•{名字}之帽"。
- 玉级帽子：冠，创意 +22，13 级可穿。
- 铉级帽子：创意 +40。店里有命名玉帽的餐厅升到**六星**后，一分钟内会收到一封邮件，附件是同名的铉级帽子；每顶玉帽只换一次，玉帽本身保留。
