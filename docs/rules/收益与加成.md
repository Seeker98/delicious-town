# 经营收益与加成的计算方式

本文说明每一轮（4 分钟）经营结算怎么算出银币、经验和耗油，多个加成怎么叠加，遇到极端数字怎么处理。对应代码：`apps/server/src/modules/settlement/`（`rates.ts` 汇总各项率，`tables.ts` 逐桌分配，`settle.ts` 收尾），数值在 `packages/config/data/game/tuning.json`，区服可以在后台覆盖。

## 1. 一句话总结

1. 同一类加成（上座率、挑剔率、银币率、经验率……）**各来源直接相加**（加算），不会互相相乘。
2. 每张桌子先算出"这桌的银币 / 经验 / 油"，全店加总。
3. 全店合计再**乘一次** `(1 + 银币率)`、`(1 + 经验率)`、`(1 + 耗油率)`（乘算只发生在这一步）。
4. 结果向下取整；有收入时至少为 1。

所以两个 +50% 银币率叠在一起是 +100%（×2），不是 ×1.5×1.5。

## 2. 各项率怎么汇总（`rates.ts`）

星级记作 s。"加成"指勋章、街道勋章、设施、牌匾、荣誉、套装等所有来源的同名键之和（`effect_source` 汇总）。

| 项 | 公式 | 限制 |
|---|---|---|
| 上座率 | 0.3 + 0.05s + 食谱加成 + 加成.atRate + 天气 + 祝福 + 负声望(-0.8) + 浮动 | 截到 [0, 1] |
| 挑剔率 | 0.1 + 0.06s + 加成.spRate + 天气 + 浮动 | 截到 [0, 1] |
| 银币率 | 加成.coinRate + 集牌匾 + 集荣誉 + 集盆栽 + 集名画 + 天气 + 祝福 + 挑剔溢出 | 不截断，可以为负 |
| 经验率 | 加成.expRate + 星潜力 + 集牌匾 + 集荣誉 + 集盆栽 + 集名画 + 天气 + 祝福 + 上座溢出 | 不截断 |
| 每桌银币 coinValue、每桌经验 expValue、每桌耗油 oilValue | 加成 + 天气 | 见第 4 节 |
| 耗油率 | 加成.oilRate + 天气 | |
| 幸运 | 基础幸运 + 加成.luckValue + 天气 | 幸运率 = √(3·min(幸运,300)) + √(max(幸运−300,0))/2，再 /100 |

- 食谱加成 = Σ（各品级已学道数 × 该品级每道加成 × 品级）。
- 星潜力：0 星 +60%、1 星 +45%、2 星 +30%、3 星 +15%、4 星起 0。
- 浮动：上座浮动 = (0.3 + 0.1s)×(随机 − 0.5)；挑剔浮动 = 0.1s×(随机 − 0.65)（偏向减少）。
- 溢出：上座率超过 1.2 的部分 ÷1.5 加到经验率（有"上座转经验"荣誉时不除）；挑剔率超过 1 的部分 ×0.5 加到银币率（需要阿雕荣誉）。
- 0 星餐厅不受天气影响。
- 银币转经验打开时：银币率 ×1.5 转成经验率，银币率归零。
- 上座桌数 = round(上座率 × 餐桌数)，只有编号不超过这个数的空桌会来客人。

## 3. 每张桌子（`tables.ts`）

每桌的基础值：银币 `10 − ⌊s/2⌋`，经验 `2 + ⌊s/2⌋`，油 `2`。

依次判定这桌来了什么：

| 顺序 | 情况 | 这桌的银币 |
|---|---|---|
| 1 | 白食桌 | 店主被吃掉银币（负数），见第 4 节 |
| 2 | 蟑螂桌 | 0（有灭蟑药时按概率清掉） |
| 3 | 痞老板坐着 / 刚出现 | 基础 ×5（银币、经验、油都 ×5） |
| 4 | 自然出蟑螂 | 0 |
| 5 | 编号超过上座桌数 | 空桌，0 |
| 6 | 章鱼哥（3 星起） | 1 |
| 7 | 按挑剔率判定为挑剔顾客 | 见下表 |
| 8 | 其他 | 普通顾客：基础银币 |

挑剔顾客先要一个品级要求 req = 1 ~ min(s, 7) 随机（0 星为 1），再从已学的食谱里随机点一道（本街食谱的概率 0.95 − 0.1s，新手街按 1 算）：

| 情况 | 银币 | 经验 |
|---|---|---|
| 点到的菜品级 ≥ req（满意） | 基础 + **菜价 × (1 + 品级加成)** | 基础 + 品级（外街菜 ×2） |
| 点到的菜品级 < req（不满意） | (基础 + 品级) ÷ 2 | 基础 + 品级（外街菜 ×2） |
| 一道菜都没学（点不到） | 基础 ÷ 2 | 基础 ÷ 2 |

- 品级加成：普通 +20%、中品 +40%、上品 +60%、极品 +80%、金牌 +100%、珍品 +120%……
- 有二哈荣誉时不满意不减半。
- 满意时还会吃特色菜（见第 6 节）。
- 挑剔顾客里还有很小概率是蟹老板（新手街不出现）：满意时银币 = 基础 + 菜价 × (1 + 品级加成) × 5，并给"蟹老板"勋章；不满意减半并给"蟹老板-生气"勋章。

最后每桌加上 `每桌银币 coinValue`（设施、勋章给的固定值）得到这桌的银币。

**菜价和收益的关系**：只有"挑剔顾客 + 点到已学的菜 + 品级够"这一种情况会用到菜价。普通顾客永远只付基础银币。所以收益主要取决于挑剔率和已学高品级食谱的多少，而不是桌子数。

### 例子（开发库里的餐厅 25，1 星，coinValue = 3，银币率 +90.2%）

| 桌 | 情况 | 这桌银币 |
|---|---|---|
| 1 | 挑剔，点到中品菜（价 640），满意 | 10 + 640×1.4 + 3 = 909 |
| 3 | 挑剔，点到上品菜（价 610），满意 | 10 + 610×1.6 + 3 = 989 |
| 2、4、5 | 普通顾客 | 10 + 3 = 13 |
| 6、7 | 空桌 | 0 |

全店 = (909 + 989 + 13×3) × (1 + 0.902) = 1937 × 1.902 = 3684.2 → **3684**，与收益记录一致。

### 没学菜时的保底

- 普通顾客照常付基础银币（约 10）。
- 挑剔顾客点不到菜：银币、经验都减半。
- 所以没学菜时每桌大约 5~13 银币，靠的是上座率和桌数。

### 新手街

- 新手街勋章：上座率 +35%、**挑剔率 −35%**、每桌银币 +1、幸运 +36。
- 挑剔率 = 0.1 + 0.06s − 0.35，0~4 星时 ≤ 0，截到 0：**没有挑剔顾客，没人点菜**，每桌只收基础银币（5 星起才有约 5% 的挑剔顾客）。学菜在新手街基本不会变成收益，搬到别的街后才体现。
- 新手街不出现蟹老板；本街 / 外街菜不区分。

## 4. 取整和极端值（`settle.ts`、`tables.ts`）

| 规则 | 说明 |
|---|---|
| 全店银币 / 经验 / 油 | `⌊合计 × (1 + 率)⌋`；合计 > 0 时至少 1 |
| 率为 0 | 直接取 `⌊合计⌋` |
| 合计 ≤ 0（例如被白食） | 不乘加成，直接取 `⌊合计⌋`（可以为负，不会因为银币率变成更大的负数） |
| 每桌经验、油加固定值 | 原值为 0 时保持 0；加上之后 ≤ 0 时取 0（负的 expValue / oilValue 不会让一桌变成负数） |
| 每桌银币加 coinValue | 直接相加，不截断 |
| 全服经验倍率 | 每桌经验 × expMultiplier（后台可调），再进入上面的汇总 |
| 实际耗油 | 不超过当前油量；油用完停业，加油后恢复 |
| 各项率的小数 | 汇总时保留 9 位小数，避免浮点误差 |

## 5. 痞老板和蟹老板

**痞老板**（每个区服一个驻留店）：
- 没有驻留店时，从营业中、1 星以上、不在冷却期的店里随机选一家。
- 在驻留店里，每桌每轮有 (0.01% + 0.001%×s) 的概率出现（每轮最多一次，店里已经坐着他时不再出现），出现后店主得到"痞老板"勋章。
- 痞老板勋章在赶走前一直有效：**上座率 +50%、挑剔率 −120%（挑剔顾客不来，没人点菜）、每桌耗油 +5**。对学了菜的店来说是明显的损失。
- 他本人坐的那一桌：银币、经验、油都 ×5。
- 赶走（80 体力或蟹黄堡秘方书）：得声望和经验，收回勋章，痞老板离开这家店；这家店 24 小时内（`planktonHostCooldownHours`）不会再被选为驻留店。人少的区服里没有别的候选店时，小镇暂时没有痞老板。

**蟹老板**（神秘顾客）：
- 满意：勋章"蟹老板"4 小时，上座率 +10%、银币率 +50%、经验率 +50%。
- 不满意：勋章"蟹老板-生气"2 小时，上座率 −10%、银币率 −50%、经验率 −50%（有非洲复兴纪念碑时可以花体力赶走）。

## 6. 特色菜（子项目 4A）

**在售**：一家店同一时间只能卖一道特色菜（一批）。结算时每桌按顾客消耗份数：

| 顾客 | 份数 | 银币 | 经验 |
|---|---|---|---|
| 普通顾客 | 1 | 每份价值 × 0.5 | 1 |
| 挑剔顾客，点到的菜品级够 | 2 | 每份价值 × 2 | 特色菜等级 |
| 挑剔顾客没满足，但有阿狸 | 1 | 每份价值（没学过这道菜时减半） | 特色菜等级（没学过时 1） |
| 章鱼哥 | 4 | 1（有魔笛时算经验） | 1 |

以上银币、经验再乘特色菜银币率 / 经验率（`mcCoinRate` / `mcExpRate`）。份数卖完这一批就结束。

**烹制**（1 星起）：批数 1、5、10、15、25、50，每批每种食材各 1 个。
- 品级：随机数 + 幸运/8 + (熟练度等级−1)×4% + 加成和天气的 `mcGoldRate`，落在 [0.5, 0.8, 0.95, 1.05, 1.15, 1.25] 的哪一段就是几品，≥1.25 为佳肴；加成把品级抬上去时标"幸运"。
- 份数：360 × 批数 ×（6 级菜 0.70~0.95）× 份数系数 ×（1 + 道份数加成 + `mcNumRate` + 厨力项）。道份数加成：同道每道已学 +2%（上限 30%），他道每道 +0.5%（上限 10%）；厨力项 = √(厨力×2)/400 × 随机数。
- 每份价值：营养值 × 份数系数 ×（1 + 熟练度加成 + 试炼价值%）+ 人类之子名画 + 集名画 + 幸运饼干。
- 熟练度 += 品级 × 份数 / 200，累计到 200、800、1800……升级，10 级满。
- 6 级特色菜必得海绵宝宝勋章（特色菜经验 ×3，3 小时）；其他按 0.0002 × 营养值 × 批数 的概率。

**品尝**：好友吃 2 份得 每份价值 的体力，非好友吃 1 份得一半；每天 2 次，同一批只能吃一次。每批前 20 次品尝有奖励：品尝者有小概率得神秘食谱，店主得神秘礼券。

**昨日冠军**：每天 9 点，昨天开始烹制的批次里 份数 × 每份价值 最高的店（并列都算）得蟹黄堡秘方。

## 7. 神殿（子项目 4B-1）

**守护兽**：每人每天一只，血量 10000 + 5000 × 星级。
- 飞弹：命中率 = 飞弹命中 + 幸运率/4 + 天气；暴击率 = 飞弹暴击 + 勋章 + 天气；暴击伤害 × 暴击倍数。
- 暴击时：10% + 幸运率/4 掉神秘礼券（1 ~ 伤害/100 张），3% + 幸运率/20 掉探险图；有捕梦网时还可能掉厨神玉玺（极速飞弹 32%，其他 3%）。
- 每次攻击按 总伤害/100 次抽美味券（有捕梦网 ×2）。
- 击败：25% + 幸运率/4 得 1 个 7 级食材；3、2、1 级食材各约 20、30、60 个。

**探险**：每次扣 1 张图和图上写的体力。
- 成功率 = 图的成功率，有欲望之针补一半失败率，减天气迷路率，加套装探险加成，再加 幸运率/12。
- 成功时：神秘食材概率 = 图 + 煤油灯 + 欲望之针 + 保安证 + 天气，再加 幸运率/20；普通食材 4 级拿 75%，其他等级 25%。
- 有煤油灯时得经验 = 每次体力 × 餐厅等级 × (成功×5 + 失败×2)。

**试炼**：注射（25 万银币，创意 +25）或冥想（免费，创意 +5）准备，勋章 1 小时；从已学的 ≤5 级特色菜里抽试炼对象。
- 成功率 = min(0.6, 0.05 + 创意/750 …) + (主料等级 − 菜等级)/80 + (辅料等级 − 菜等级)/160 + (200 − 主料权重 − 辅料权重)/1500 + 幸运率/5。
- 成功：主料稀有（权重 < 100）时试炼价值 +1~2%（上限 50%）；试炼经验 +1~4%（上限 150%）；熟练度 +800 × 熟练度等级。

**克拉肯**：每天想吃一道 1~5 级特色菜（全区服相同）；11~14 点、17~21 点可以投喂一次。
- 好感度按份数、每份价值、是否它想吃的菜（×2.4）/ 同道（×1）/ 其他（×0.5）计算。
- 奖励：√好感度 + 2 颗种子；种子多时可能得蟹币；好感度 > 35 时 30% 得触手。
- 好感度为负：扣这道菜的试炼经验 → 试炼价值 → 都没有时 25% 遗忘这道菜。

**触手商店**：每天 6 格特色菜残卷，用"特色菜等级"条触手换一张；每天第一次刷新免费。
