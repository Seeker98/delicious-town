# 举报和处罚

本文说明玩家举报和协管处理的规则。对应代码：`apps/server/src/modules/report/`、`apps/server/src/modules/admin/ban.ts`；数值在 `tuning.report`。

## 1. 能举报什么

- 论坛帖子、论坛回复；
- 新闻里别人用喇叭发的广播；
- 别人店里的店名、店铺公告。

举报按钮在这些内容旁边，自己的内容没有举报按钮。

## 2. 怎么举报

- 选一个理由：辱骂、色情、广告、政治、其他；可以补 100 字以内的说明。
- 每个账号每天最多举报 10 次。
- 不能举报自己；同一条内容只能举报一次。
- 同一条内容被多人举报，协管看到的是"被 N 人举报"的一个案子。
- 协管驳回过、之后没改过的内容，再被举报不会重新开案；内容改了才会。

## 3. 协管怎么处理

协管在后台"举报"页逐个案子处理：

| 内容 | 处理 |
|---|---|
| 帖子、回复 | 删除 |
| 喇叭 | 撤下 |
| 店铺公告 | 清空 |
| 店名 | 强制改名（默认"餐厅{店号}"） |

- 处理时可以同时封号：协管能封 1 天或 7 天；永久封号只有管理员能做。
- 内容不违规就驳回。
- 内容已经被作者自己删掉或改掉时，案子照样能结，也照样能封号。

## 4. 邮件

- 举报人：处理后收到"你举报的……已处理"，驳回后收到"……经核实未违规"。
- 被处理的人：收到"违规处理通知"，写明处理了什么、封号多久和协管的说明。

## 5. 封号

- 封号会立刻踢下线。
- 有期限的封号到期后自动解封，可以直接登录。
- 解封只有管理员能做。
- 被封号期间不进排行榜，也不能和别人互动。
