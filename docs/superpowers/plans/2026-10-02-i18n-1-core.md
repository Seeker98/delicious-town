# 多语言第 1 批（框架 + 第一批文案）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 玩家界面能在简中、繁中、英、法、西五种语言之间切换，语言存在账号上；导航、登录注册、我的账号、首页、报错、新闻、日志、标签先翻好，其余页面暂时显示中文。

**Architecture:** 前端每种语言一个按区域拆分的翻译对象，简中的对象是类型来源，其他语言必须结构完全一致（类型检查保证）；Pinia 的 locale store 管当前语言和按需加载，`useT()` 给模板用，`activeMessages()` 给普通函数用。繁中从简中源码用 OpenCC 生成。账号表加 `lang`；道具目录接口按 `lang` 返回名字和说明，配置构建时生成各语言的名字表（这一批只有繁中的自动转换，其他语言的数据文件先空着）。

**Tech Stack:** Vue 3 + Pinia + TypeScript strict、Fastify + Kysely、zod、Vitest、Playwright、opencc-js（新增）。

**Spec:** `docs/superpowers/specs/2026-10-02-i18n-design.md`

## Global Constraints

- 语言：`zh-CN`（默认）、`zh-TW`、`en`、`fr`、`es`，列表放在 `@dt/shared` 的 `LOCALES`。
- 管理后台（`views/admin/**`、`components/admin/**`）只用中文，不抽取。
- 简中对象是类型来源：`export type Messages = typeof zhCN`；其他语言写成 `const x: Messages = {...}`，不允许 `as` 绕过。
- 缺译显示中文（游戏数据回退到简中原文）。
- 繁中由脚本生成，文件头写"自动生成"；人工修订写在覆盖表里。
- 账号 `lang` 可为空，空表示还没选过。
- 浏览器语言判断：`zh-TW / zh-HK / zh-Hant*` → zh-TW；其他 `zh*` → zh-CN；`fr*` → fr；`es*` → es；其余 → en。
- 单元测试的默认语言是 zh-CN，现有断言中文文案的测试不用改。
- 不新增除 opencc-js 以外的依赖。

## Review Focus

1. 切换语言后，道具、食材、天气这些名字跟着变（目录要按语言重新读，缓存按"版本 + 语言"分开）——Task 4 的测试钉住。
2. 浏览器里存的或账号上的语言值不合法（手改、旧版本）：回退到 zh-CN，不白屏——Task 2、Task 5 的测试钉住。
3. 切换语言时翻译包加载失败（离线、部署中）：保持原语言并提示，不卡在半切换状态——Task 2 的测试钉住。
4. 法语数字格式用窄不换行空格分千位，和中文不同；默认语言下现有测试里的"3,000,000"不能变——Task 2 的测试钉住。
5. 改了简中文案却没重新生成繁中：CI 报错——Task 3 的测试钉住。

```ts
// packages/shared/src/locale.ts
import { z } from 'zod';

/** 支持的语言（问题记录 272）：简中默认 */
export const LOCALES = ['zh-CN', 'zh-TW', 'en', 'fr', 'es'] as const;
export type Locale = (typeof LOCALES)[number];
export const DEFAULT_LOCALE: Locale = 'zh-CN';
/** 语言选择里显示的名字（用各自的语言写） */
export const LOCALE_NAMES: Record<Locale, string> = {
  'zh-CN': '简体中文',
  'zh-TW': '繁體中文',
  en: 'English',
  fr: 'Français',
  es: 'Español',
};
export const localeSchema = z.enum(LOCALES);

export function isLocale(x: unknown): x is Locale {
  return typeof x === 'string' && (LOCALES as readonly string[]).includes(x);
}

/** 浏览器语言 → 支持的语言：按顺序取第一个能判断的；都判断不了用英语 */
export function detectLocale(tags: readonly string[]): Locale {
  for (const raw of tags) {
    const t = raw.toLowerCase();
    if (/^zh-(tw|hk|mo|hant)/.test(t)) return 'zh-TW';
    if (t === 'zh' || t.startsWith('zh-')) return 'zh-CN';
    if (t === 'fr' || t.startsWith('fr-')) return 'fr';
    if (t === 'es' || t.startsWith('es-')) return 'es';
    if (t === 'en' || t.startsWith('en-')) return 'en';
  }
  return 'en';
}
```

```ts
// apps/web/src/i18n/index.ts
import { DEFAULT_LOCALE, type Locale } from '@dt/shared';
import zhCN from './locales/zh-CN';

/** 简中的翻译对象是类型来源：其他语言必须结构完全一致（问题记录 272） */
export type Messages = typeof zhCN;

const LOADERS: Record<Exclude<Locale, 'zh-CN'>, () => Promise<{ default: Messages }>> = {
  'zh-TW': () => import('./locales/zh-TW'),
  en: () => import('./locales/en'),
  fr: () => import('./locales/fr'),
  es: () => import('./locales/es'),
};
const cache = new Map<Locale, Messages>([['zh-CN', zhCN]]);

export async function loadMessages(l: Locale): Promise<Messages> {
  const hit = cache.get(l);
  if (hit) return hit;
  const m = (await LOADERS[l as Exclude<Locale, 'zh-CN'>]()).default;
  cache.set(l, m);
  return m;
}

let current: { locale: Locale; messages: Messages } = { locale: DEFAULT_LOCALE, messages: zhCN };
/** 普通函数（报错文案、新闻文案、数字格式）用：当前语言的翻译 */
export const activeMessages = (): Messages => current.messages;
export const activeLocale = (): Locale => current.locale;
export function setActive(locale: Locale, messages: Messages): void {
  current = { locale, messages };
}
```

注意：测试里的 `vi.spyOn(i18n, 'loadMessages')` 要能生效，store 必须通过模块对象调用（`import * as i18n from '../i18n'` 后调用 `i18n.loadMessages(l)`）。

```ts
// apps/web/src/stores/locale.ts
import { defineStore } from 'pinia';
import { DEFAULT_LOCALE, detectLocale, isLocale, type Locale } from '@dt/shared';
import * as i18n from '../i18n';
import zhCN from '../i18n/locales/zh-CN';

const KEY = 'dt_locale';
function saved(): Locale | null {
  try {
    const v = localStorage.getItem(KEY);
    return isLocale(v) ? v : null;
  } catch {
    return null;
  }
}

export const useLocaleStore = defineStore('locale', {
  state: () => ({ locale: DEFAULT_LOCALE as Locale, messages: zhCN as i18n.Messages }),
  actions: {
    /** 启动时：浏览器里存的 → 按浏览器语言判断 */
    async init() {
      await this.set(saved() ?? detectLocale(navigator.languages ?? [navigator.language]));
    },
    /** 加载失败返回 false，保持原语言；save 为 true 时同时存到账号（Task 5） */
    async set(l: Locale, o: { save?: boolean } = {}): Promise<boolean> {
      let m: i18n.Messages;
      try {
        m = await i18n.loadMessages(l);
      } catch {
        return false;
      }
      this.locale = l;
      this.messages = m;
      i18n.setActive(l, m);
      document.documentElement.lang = l;
      try {
        localStorage.setItem(KEY, l);
      } catch {
        // 存储不可用时忽略
      }
      void o;
      return true;
    },
  },
});
```

```ts
export function formatNum(n: number): string {
```

```js
// 从简中翻译源码生成繁中（问题记录 272）：整份文件做 OpenCC 转换（只影响汉字），再套用人工修订
import { readdirSync, readFileSync, writeFileSync, mkdirSync } from 'node:fs';
import { dirname, join } from 'node:path';
import { fileURLToPath } from 'node:url';
import * as OpenCC from 'opencc-js';

const ROOT = join(dirname(fileURLToPath(import.meta.url)), '../src/i18n');
const HEADER = '// 自动生成：由 scripts/gen-zh-tw.mjs 从 zh-CN 转换，不要手改；修订写在 src/i18n/zh-TW-overrides.json\n';
const toTw = OpenCC.Converter({ from: 'cn', to: 'twp' });
const overrides = JSON.parse(readFileSync(join(ROOT, 'zh-TW-overrides.json'), 'utf8'));

export function convertZhTw(source) {
  let out = toTw(source);
  for (const [from, to] of overrides) out = out.split(from).join(to);
  return HEADER + out;
}

if (process.argv[1] && fileURLToPath(import.meta.url) === process.argv[1]) {
  const from = join(ROOT, 'locales/zh-CN');
  const to = join(ROOT, 'locales/zh-TW');
  mkdirSync(to, { recursive: true });
  for (const f of readdirSync(from).filter((x) => x.endsWith('.ts')))
    writeFileSync(join(to, f), convertZhTw(readFileSync(join(from, f), 'utf8')));
  console.log('zh-TW generated');
}
```

`zh-TW-overrides.json` 初始为 `[]`。注意：zh-CN 源码里 `const zhCN = { ... }` 转换后变量名不变（ASCII），但 zh-TW 的 `index.ts` 需要类型注解——在 zh-CN/index.ts 里不写类型、zh-TW 由转换得到同样的代码，`Messages` 由 zh-CN 推导，zh-TW 结构天然一致；键检查由上面的运行时测试兜底。
