# 猜酒杯改版 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** 猜酒杯改成一局闯关：4 轮杯子 2、3、5、7 个，猜中可以收手拿这一档的奖励或继续，猜错什么都没有；每局 1 张神秘礼券。

**Architecture:** 照秘制调料、一掷千金：
- 局面存 `bar_round`，`game = 'cup'`；
- 新闻每日计数 `bar.cup.news`；
- 概览沿用 `peekRounds`，查询条数不变；
- 胜率函数放在 `rules.ts`；
- 服务端新文件 `cup.ts` 取代 `games.ts` 里的 `playCup`；
- 前端重写 `CupPanel`。

**Spec:** `docs/superpowers/specs/2026-10-07-bar-cup-v2-design.md`

## Global Constraints

- 同前几个游戏：
  - 四种语言，zh-TW 最后生成；
  - 叫法一致：en Mystery Vouchers / bartender / renown / coins；es vales misteriosos / barman；fr bons mystère / barman；
  - 法文“名字×数量”写 ` ` 转义；
  - 规则文案不出现字母变量；`.vue` 不写中文；
  - 不加迁移；`/bar` 查询预算不升；
  - 新数值都写 `setting_docs`；
  - 状态原因带 `cup_` 前缀；
  - 改了 config、shared 后要 build；
  - 提交末尾写 Co-Authored-By；`git add` 只加明确路径；
  - 推送前跑 `pnpm lint`、`pnpm format:check`。
- 前端：
  - 固定的读屏播报区；
  - 按钮标签带状态；
  - 出错时局没了回到开局，否则用概览里的局面再重新读；
  - 格子用 `minmax(0, 1fr)`。
- 数值：

```
cup: { cost: 1, cups: [2, 3, 5, 7], maxRate: 0.95,
  tiers: [ { awards: 1, level: 2, news: null }, { awards: 2, level: 4, news: null },
           { awards: 4, level: 6, news: 'news' }, { awards: 8, level: 10, news: 'broadcast' } ] }
```

## Review Focus

1. 状态机不能被绕过：
   - 猜中后没选就再猜；
   - 没猜中就收手、继续；
   - 没有局时收手、继续；
   - 杯子编号越界（按这一轮的杯子数）。
2. 开局只在没有局时扣礼券；礼券不够不扣、不建局、不计活跃。
3. 猜错时骰子一定在别的杯子里；猜中时就在选的杯子里。
4. 新闻和广播合计每家店每天最多一条。
5. 连胜、连败按局计；排行“酒吧连胜 / 连败”读得到。

### Task 2：共享类型

- `bar.ts`：删 `barCupBody`、`CupResultDto`；加

```ts
export const barCupGuessBody = z.object({ cup: z.number().int().min(0).max(99) });
export interface CupGuessDto { pick: number; ball: number; win: boolean; lucky: boolean }
export interface CupDto {
  /** 这一轮，从 0 起 */
  round: number;
  cups: number;
  /** 这一轮已猜中，等玩家选收手或继续 */

}
export interface CupTierDto { awards: number; news: 'news' | 'broadcast' | null }

cup: BarGameDto & { cost: number; cups: number[]; tiers: CupTierDto[]; round: CupDto | null };
```

- `news.ts`：`NEWS_TYPES` 加 `'bar.cup.big'`，`BROADCAST_STYLE_NEWS` 加 `'bar.cup.big'`。
- 测试：`barCupGuessBody` 拒负数、接受 0。

### Task 3：胜率（纯函数）

- `rules.ts`：删 `cupRound`；`cupWinRate(cups, luckRate, maxRate) = min(maxRate, (1 + luckRate) / cups)`。
- 测试：`(2, 0, 0.95)` 得 0.5；`(7, 0.4, 0.95)` 得 0.2；`(2, 1, 0.95)` 得 0.95。
- 提交。

### Task 4：服务端

- 新建 `cup.ts`、`cup.test.ts`；删 `games.ts` 里的 `playCup` 和 `games.test.ts` 里的猜酒杯测试；改 `round.ts`（`BarGame` 加 `'cup'`）、`view.ts`、`service.ts`、`routes.ts`。
- `CupState`：`{ round: number; won: boolean; last: CupGuessDto | null }`（`last` 留着，刷新后能看到翻开的杯子）。
- **guess(cup)**：
  - 有局：`won` 时报 `cup_decide`。
  - 杯子编号 ≥ 这一轮杯子数（没有局时按第 1 轮）报 `badInput('cup')`，在扣礼券之前。
  - 没有局：`consumeGoods(cost)`，`emitAction('bar.play')`、`emitAction('bar.cup')`，局面 `{ round: 0, won: false, last: null }`。
  - 随机数顺序：猜中 → 猜错时骰子在哪（`rng.int(cups - 1)`，跳过选的那个）。
  - 猜中：最后一轮就通关（同收手的发奖，`result: 'clear'`）；否则 `won = true` 保存。
  - 猜错：删局面，连败 +1，`restLog('bar.cup', { result: 'lose', round })`，`result: 'lose'`。
- **stop**：没有局 `no_round`；没猜中 `cup_not_won`；发奖结束。
- **next**：同样两种错误；`round + 1`，`won = false`，`last = null`，保存。
- **发奖**（stop、clear 共用）：
  - 删局面；按这一档 `awards` 次 `randomAward(o, { level, noTicket: true, bar: true })`；
  - 连胜 +1（`nextTimes`，`lockBarState` / `saveBarState`）；
  - 这一档有 `news` 且 `incrementDaily('bar.cup.news') === 1` 时写新闻：`news` → `bar.cup`，`broadcast` → `bar.cup.big`，参数 `{ round: 第几轮（从 1 起）, cups }`；
  - `restLog('bar.cup', { result, round: 从 1 起, awards: 份数 })`。
- 概览：`cup: { result, times, cost, cups, tiers: tiers.map({awards, news}), round: cupView }`。
- 测试照 spec §9；随机数用 script 控制；测新闻、通关时直接写局面。
- 跑 bar、budget、rank 测试；提交。

### Task 5：前端

- 重写 `CupPanel.vue` 和测试；改 `endpoints.ts`（`barCupGuess`、`barCupStop`、`barCupNext`，删 `barCup`）、`testData.ts`、`main.css`（`.dt-cup-grid`）。
- i18n 四种语言：`bar.ts`（`cup` 一组重写、雯姐那句）、`errors.ts`（`cup_decide`、`cup_not_won`）、`events.ts`（`bar.cup`）、`news.ts`（`bar.cup` 新旧两种参数、`bar.cup.big`）。
- 面板：
  - 规则一行；奖励表 `cup-tier-i`（第几轮、几个杯子、几份奖励、上新闻 / 全服广播）；没有局时写每局几张礼券，礼券不够写原因、杯子灰掉。
  - 杯子 `cup-i`（从 0 起），读屏标签写编号和状态（你选的、骰子在这里）。
  - 猜中、不是最后一轮：`cup-won` 提示，`cup-stop`、`cup-next` 两个按钮；此时杯子不能点。
  - 结束：`cup-result`（奖励逐份列出或“猜错了，骰子在 x 号杯”），`cup-again`。
  - 连胜行 `cup-streak`。
  - 固定播报区 `cup-live`。
- 测试覆盖：开局猜、猜中后的两个按钮、继续后杯子变多、收手、通关、猜错、读屏、出错时的处理、礼券不够。
