# 游戏接口防脚本 实现计划（PR②：可疑号人机验证、签名代码混淆）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 后台能对某个账号打开“需要人机验证”（带到期时间），打开后这个账号的写请求每隔一段时间要过一次 Cloudflare 人机验证，网页弹出验证框、通过后自动重发；网页的签名代码在构建时单独混淆、每次构建不同。

**Architecture:** 服务端在 PR① 的防脚本钩子里，签名校验之前加一道“人机验证”检查：名单（新表 `antibot_challenge`，照白名单的缓存做法）里的账号，Redis 里没有“最近验证过”的标记时，要求请求头 `x-dt-captcha` 带 Turnstile 令牌，校验通过后记标记。网页 `client.ts` 收到 `CAPTCHA_REQUIRED` 时调 App 注册的处理函数（底部面板里放现有的 `TurnstileBox`），拿到令牌重签重发一次。混淆用构建插件只处理签名相关的两个模块。

**Tech Stack:** Fastify、ioredis、Kysely 迁移、Vue 3 + pinia、Cloudflare Turnstile（`infra/captcha.ts`、`components/TurnstileBox.vue` 已有）、vitest；混淆用 `rollup-plugin-obfuscator`（底层 `javascript-obfuscator`）。

**Spec:** `docs/superpowers/specs/2026-10-25-anti-bot-design.md` 第 6、7 节（PR① 已合并为 #341）。

## Global Constraints

- 人机验证只由后台手动打开（`admin` 角色），带到期时间；不自动打开。
- 打开后要求验证的间隔是区服设置 `tuning.ops.antibot.captchaEveryMin`，默认 `60`（分钟）。
- 人机验证和签名的“只记录 / 拦截”模式**无关**：管理员打开了就要验证；但 `ANTIBOT_FORCE_LOG=true` 时也跳过（总开关一律放行），白名单账号也跳过。
- 不要求验证的请求：后台接口 `/api/v1/admin/*`、账号接口 `/api/v1/account/*`（登录、注销、改密码等，避免把人锁在外面）、开放接口、测试接口、所有读请求。
- 没带令牌或令牌校验不过：只让这一下失败，返回 `ErrorCode.CAPTCHA_REQUIRED`（HTTP 403，`params.reason` 为 `missing` 或 `failed`）。
- 网页：令牌只用一次；用户关掉验证框就按原错误抛出，不重试；一次请求最多为人机验证重发一次。
- 混淆只作用于网页的签名模块，不影响服务端，不影响其余前端代码的报错定位；引入的代价超过下面 Task 5 的门槛就不做，回来报告。
- 玩家看的简中文字用半角括号、英文冒号逗号；繁中跑 `pnpm i18n:tw` 生成，不对它跑 prettier；法文窄空格写 ` ` 转义。
- 推送前跑 lint、`prettier --check .`、三个包的测试；类型检查分包看退出码。只 `git add` 明确路径。
- 别叠 PR：这个分支从合并了 #341 的 main 开出（`feat/anti-bot-2`）。

## Review Focus

1. **玩家在验证框里关掉或网络失败**：期望这一下操作失败、提示要先完成人机验证，不会卡住“处理中”、不会无限弹框。→ Task 4 测试。
2. **同时连点好几个写请求**都撞上 `CAPTCHA_REQUIRED`：期望只弹一个验证框，几个请求共用这一次的令牌依次重发（令牌服务端只校验一次，之后靠 Redis 标记放行）。→ Task 2、Task 4 测试。
3. **到期以后**：名单里过了到期时间的账号不再要求验证（名单缓存要按当前时间判断，不能只看在不在表里）。→ Task 1 测试。
4. **被要求验证的人去注销、改密码**：照常，不弹框。→ Task 2 测试。
5. **Turnstile 服务出错**（`captcha.verify` 返回假或抛错）：只让这一下失败，不 500。→ Task 2 测试。
