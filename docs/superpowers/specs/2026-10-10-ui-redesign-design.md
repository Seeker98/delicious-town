# 界面全面改版 设计

- 日期：2026-10-10
- 来源：用户 2026-10-10 提出“原作是 2010 年代的游戏，网页一直没好好做样式，想看看跳出现有视觉规范能做到什么程度”。要求：主题色换成紫水晶色；所有页面都过一遍；图形用 SVG（包不能太胖）；要深色模式；2010 年代的页面结构也要重新考虑，层级里的不一致要一并修掉；改得不够就推倒重做。
- 本文取代 [视觉规范.md](../../design/视觉规范.md) 和 [文字链接-2026-10-07.md](../../design/文字链接-2026-10-07.md)，P1 落地时把这两份改写成新版。
- 不涉及菜园的布局和功能（第 7 节）。

## 1. 用户已定的取舍

1. 风格：以“暖萌游戏”为主（圆角、图形、彩色小图标），读的页面（小镇日报、资料库、更新记录）带一点“报刊”味道（衬线标题、细线）。
2. ~~密度不能降~~（2026-10-11 改，见第 1.1 节）：密度可以适当降，换更清楚的层级和更大的图形。
3. 紫色只给能点的东西用；不能点的强调用加粗或琥珀色（第 2.6 节）。
4. 宽屏保持单栏（玩家基本用手机），不做多栏。
5. 图形：用 SVG，做到 C 档（界面图标 + 内容图形 + 区域头图 + 食材按类配图）。风格混用：界面图标用“D 单色紫调”，内容图形用“B 无描边扁平”（第 3 节）。
6. 深色模式：要，三选一（跟随系统 / 浅色 / 深色），默认跟随系统。
7. 保留 Bootstrap，但最终长相完全由我们决定：先把它的变量和组件样式全部接管，分批改页面时把组件类换成自己的，收尾时只留重置、栅格、工具类（第 2.8 节）。
8. 底部导航：餐厅、食谱、橱柜、菜场、好友不动，“更多”换成“小镇”页；账号类收进顶栏的“我”（第 4 节）。
9. 新增“银行”（盖乐瑞基金 + 理财）；商店的“今日特价”改名“限时折扣”。
10. 推进方式：先打地基，再按模块分批，每批一个 PR，合完再开下一个（第 6 节）。许愿树合并后才开始改代码。
11. 所有 `dt` 前缀（CSS 类、CSS 变量、本地存储键、cookie、包名）保持不变，不改名。

### 1.1 方向调整（2026-10-11）

P1~P4 合并后用户指出：页面本身只是换了皮，没有真正重做。原因是“首屏信息量不少于改前”把页面主体钉成原来的几行，每批都只是套卡片、换控件。用户看过三页样稿（[视觉方向样稿](https://claude.ai/artifact/DPpPNDrEuLwu3VFXYK5jSA)：首页、橱柜、菜场各一版“A 清楚的账本”和“B 小镇橱窗”）后定下：

1. **首页用 B，橱柜用 B，菜场用 A 的列表加 B 的购买面板。** 以后的页面按下面的规则选。
2. **每页一个主角**：首屏最显眼处放这一页最要紧的状态或动作（首页：营业状态和加油；橱柜：食材格子；菜场：今天的货和价格）。主操作是整宽 46~48px 的胶囊按钮。
3. **密度按页面类型定**，不再要求“不少于改前”：
   - 比较类（菜场、食谱、收益、排行、交易）：行式列表，390×844 一屏至少 6 行。行里不放步进器，右边只有一个按钮（菜场是价格按钮）。
   - 收集类（仓库、纪念品、厨具）：背包格子，4 列，40px 图（橱柜 2026-10-12 改成列表），右上角数量，2 级以上和特殊类用底色区分；点一格从底部弹出详情面板（大图、持有、进度、操作）。
   - 状态类（首页、区域首页）：大卡片、大数字、2×2 的操作块。
4. **插画进页面主体**：区域首页的场景头图放大到约 196px（不再限 88px），状态可以画进场景里（比如招牌上挂“停业中”）。
5. **数量统一用底部数量面板**：大号步进器（44px 高）、快捷数量（10 / 100 / 最多）、合计和余额、整宽确认按钮。需要知道余额的接口补上余额（菜场接口加玩家银币）。
6. **等级角标**：食材 1 级不标，2 级起在名字后面标“N 级”小方块，颜色按等级。
7. 圆角加大：卡片 16px、底部面板 22px；浅色下浮起来的主角卡片可以用阴影；底部导航 6 个根页面的标题用 22px 粗体大标题。
8. 第 5 节的通用模式照旧适用，和上面冲突的以本节为准；P3、P4 已改的页面按本节再过一遍（第 6.1 节 P7）。

## 2. 设计基础（P1）

### 2.1 颜色令牌

令牌名沿用 `--dt-*`。浅色写在 `:root`，深色写在 `:root[data-theme="dark"]`。

| 令牌 | 用途 | 浅色 | 深色 |
|---|---|---|---|
| `--dt-bg` | 页面底色 | `#F4F1F8` | `#17131D` |
| `--dt-surface` | 卡片、顶栏、底部导航 | `#FFFFFF` | `#211B2A` |
| `--dt-surface-2` | 输入框、卡片里的嵌套块 | `#FAF8FC` | `#2A2335` |
| `--dt-line` | 分隔线、边框 | `#E8E2F0` | `#342C40` |
| `--dt-text` | 正文 | `#221A2E` | `#EFEAF6` |
| `--dt-muted` | 次要文字、信息行 | `#6E6680` | `#A99FBA` |
| `--dt-primary` | 主按钮底色、进度条、选中下划线 | `#7442B8` | `#B48BEA` |
| `--dt-primary-ink` | 链接、紫色文字、浅紫按钮的字 | `#6B3BAE` | `#C3A0F2` |
| `--dt-primary-soft` | 浅紫底（次要按钮、选中行、标签） | `#EEE4FB` | `#382A50` |
| `--dt-on-primary` | 主按钮上的字 | `#FFFFFF` | `#1D1430` |
| `--dt-success` / `--dt-success-soft` | 够了、成功、有利 | `#2F7A3A` / `#E6F4E8` | `#7FCF8A` / `#1F3324` |
| `--dt-danger` / `--dt-danger-soft` | 不够、危险、不能操作的原因 | `#B42D2D` / `#FBEAEA` | `#F29191` / `#3A2024` |
| `--dt-warning` / `--dt-warning-soft` | 可领奖、提醒、强调 | `#8A5A00` / `#FBF0D6` | `#F0C060` / `#3A2E14` |

- 紫水晶色阶 `--dt-amethyst-50 … 900`：`#F7F2FD #EEE4FB #DCC8F6 #C3A3EE #A57BE2 #8B5CD0 #7442B8 #5F3499 #4A2878 #2E1A4A`，供图形和少量装饰用，组件只读上表的用途令牌。
- 对比度（已算）：主按钮白字 6.53；紫色文字在白底 7.34；次要文字在页面底色 4.85、在白底 5.42；深色下的紫色文字 7.67、次要文字 6.66；三种语义色在各自底色上都 ≥ 5.3。规则：所有写字的颜色，浅色、深色两套都 ≥ 4.5，测试检查。
- 去掉的颜色：Bootstrap 的蓝、青（`alert-info`）、默认绿；现在 `main.css` 里散落的十几个裸色值全部换成令牌。

### 2.2 深色模式

- 设置放在“我 > 设置”：跟随系统（默认）/ 浅色 / 深色，存本地存储 `dt_theme`（`system` | `light` | `dark`），只跟设备走，不存服务端。
- `index.html` 里一段内联脚本在页面渲染前读设置，给 `<html>` 写 `data-theme` 和 `data-bs-theme`，并更新 `<meta name="theme-color">`。跟随系统时监听 `prefers-color-scheme` 变化。不能出现先白后黑的闪烁。
- 深色下不用阴影，靠 `bg` → `surface` → `surface-2` 三档底色分层次。
- 打开 Bootstrap 的 `data-bs-theme="dark"`，原生控件（下拉框、勾选框、滚动条）一起变深。

### 2.3 字体

- 无衬线（全站）：`system-ui, -apple-system, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans SC", sans-serif`。不加载网络中文字体。
- 衬线（只用于报刊页的标题：小镇日报、资料库、更新记录）：`"Noto Serif SC", "Source Han Serif SC", "Songti SC", STSong, SimSun, serif`。
- 字号层级：

| 层级 | 规格 |
|---|---|
| 顶栏页面标题 | 17px，600 |
| 区域头图上的标题 | 20px，600 |
| 区块标题 | 16px，600 |
| 正文、列表行名称 | 14px（名称 500） |
| 信息行 | 12px，次要文字色 |
| 标签、角标 | 11px（最小，不再有 9px、7px） |

- 数字：`font-variant-numeric: tabular-nums`，用在所有数量、价格、排行、计时上。

### 2.4 间距、圆角、阴影

- 间距按 4px 网格：`--dt-space-1 … 6` = 4、8、12、16、20、24px。高频容器沿用问题记录 439 的紧凑值：列表行上下 3px，整行可点的行至少 40px。
- 圆角：`--dt-radius-xs` 4（标签）、`--dt-radius-sm` 10（输入框、方块）、`--dt-radius-md` 14（卡片、面板）、按钮和胶囊全圆。
- 阴影只给浮起来的东西（底部弹出面板、提示胶囊、下拉菜单）：`--dt-shadow-float`；卡片在浅色下用 1px 细线，不加阴影。

### 2.5 动效

- 曲线：`--dt-ease-out: cubic-bezier(0.23, 1, 0.32, 1)`（出现、反馈）、`--dt-ease-drawer: cubic-bezier(0.32, 0.72, 0, 1)`（底部面板）。
- 时长：按下 120ms；悬停和颜色 150ms；下拉、标签下划线 200ms；面板 280ms。界面动效一律 ≤ 300ms。
- 按下：能点的东西 `scale(0.97)`。悬停效果只写在 `@media (hover: hover) and (pointer: fine)` 里。
- 只动 `transform` 和 `opacity`；不用 `transition: all`；不从 `scale(0)` 出现。
- `prefers-reduced-motion: reduce` 时去掉位移和缩放，只留淡入淡出。
- 结算数字、频繁刷新的数值不加动画。

### 2.6 能点和不能点

| 元素 | 写法 |
|---|---|
| 正文 | 正文色，不能点 |
| 强调（广播、重要数字） | 加粗或琥珀色，不用紫色 |
| 状态标签（未学、称号、进行中） | 4px 圆角的小方块，中性或语义浅底，不像按钮 |
| 整行去别处 | 整行可点，右边一个灰色 `›` |
| 句中链接（店名、玩家名） | 紫字 + 点状下划线 |
| 本页操作（签到、学习、加油） | 胶囊按钮，不再用“像链接的按钮” |
| 危险操作（丢弃、删除） | 红色描边 + 图标 |

- 按钮四种：实心紫（主操作，一处只放一个）、浅紫（次要）、纯文字（取消）、红描边（危险）。
- 不能操作：按钮变灰，原因用红字写在旁边或信息行里，不弹窗。
- 筛选胶囊选中是深色实心（正文色底），故意不用紫色，和“操作”分开。
- 焦点框：`:focus-visible` 时 2px 紫色外圈。

### 2.7 控件

P1 把下面这些全部重新定义一遍，屏幕上不能再看出 Bootstrap 的默认长相：按钮、输入框、下拉框、勾选框、开关、标签页（下划线式，选中下划线 200ms 滑动）、筛选胶囊、进度条、标签和角标、表格、提示块（取代 `alert-*`）、底部提示胶囊、弹窗。

### 2.8 Bootstrap 的处理

- 只用了它的样式（没有用它的脚本）。约 3,500 处布局和间距工具类（`d-flex`、`gap-2`、`mb-1`、`small`、`text-muted`……）保留；约 1,000 处组件类（`btn`、`form-control`、`nav-tabs`、`alert`、`badge`、`table`、`progress`、`modal`）会漏出 Bootstrap 的长相。
- P1：把 `--bs-*` 变量全部接到我们的令牌上，并重写上面每个组件的样式。
- P3~P8：改到哪个页面，就把那里的组件类换成自己的组件或 `dt-` 类。
- P9：`main.ts` 只引入 Bootstrap 的 reboot、grid、utilities 三部分，组件部分整个去掉。
- 最终效果由我们 100% 决定，Bootstrap 只剩“排版工具”的角色。

### 3.3 数据：食材和道具配哪张图

- 食材的配图类别写进配置：`packages/config/data/master/foods.json` 每条加 `art`（类别键，如 `pork`、`leafy`）。现有数据只有三大类（肉类、蔬菜水果类、调理坚果类），新街道食材还没分类，所以 336 种食材按名字一次性标注。构建校验：每种食材都有 `art`，且是已知类别。
- 道具按 `group` 配默认图，个别道具可以在 `goods.json` 里写 `art` 覆盖。
- 目录接口把 `art` 一起下发，网页不写死任何食材、道具编号（遵守 `itemLiterals.test`）。
- 食材这部分随 P4 做，道具随 P5 做。

### 3.4 接入方式

- 源文件：`apps/web/src/art/ui/*.svg`、`apps/web/src/art/content/*.svg`、`apps/web/src/art/scene/*.svg`（头图）。
- 脚本 `pnpm -F @dt/web art`：把 `ui` 和 `content` 各自拼成一张雪碧图，写到 `apps/web/src/art/generated/`（提交进仓库，和现有图标字体的做法一样）；页面用 `?url` 引入，由 Vite 加内容哈希。
- 组件 `<DtArt name="…" size="…" />`：渲染 `<svg><use href="雪碧图#名字"/></svg>`。雪碧图第一次用到时下载，之后走浏览器缓存。界面图标的颜色写成 `var(--dt-art-ink)`、`var(--dt-art-fill)`，从外层继承。
- 头图是独立文件，用 `<img loading="lazy">`。
- 装饰性的图形加 `aria-hidden`；单独表达意思的（比如只有图标的按钮）有文字标签。
- 现在的原版图包接口（`GameImg.vue`、`/pack`，线上本来就没有图包、一直显示替代图标）改成用 `DtArt`，旧接口在 P4 删掉。

### 3.5 体积和审图

- 上限：全部图形压缩后 ≤ 120KB，首屏用到的 ≤ 25KB。测试检查雪碧图和头图的体积。
- 开发环境的图库页 `/dev/art`（生产构建不包含）：浅色、深色并排展示所有图形和名字。每批的新图先进图库给用户过目，确认后再接进页面。

### 4.2 导航规则

1. 顶栏显示当前页面标题，页面里不再单独写标题行（每页省约 40px，保证页页有标题）。顶栏右边：游戏时间、邮件、“我”的头像。首页标题是店名，旁边是天气。
2. 返回只有一种：顶栏的返回箭头回到逻辑上一级。每个路由在 `meta.parent` 里写上一级；页面里的“返回论坛”“返回食谱”之类链接全部去掉。系统返回手势仍是浏览器后退。底部导航的 6 个根页面不显示返回箭头。
3. 底部导航高亮所属区域：每个路由在 `meta.section` 写属于哪个入口（`home` | `cookbooks` | `cupboard` | `market` | `friends` | `map`）。
4. 页面标题：路由 `meta.title`（文案键）；店名、NPC 名、天气这类动态标题由页面写进一个小 store，顶栏读它。
5. 分区最多两层：第一层标签页，第二层筛选胶囊，没有第三层。排行榜的子榜（第三层）改成下拉框。按钮组式的筛选全部改成胶囊。
6. 标签页统一：当前标签写进网址 `?tab=`；不带 `tab` 进入时打开上次看的（本地存储记住，沿用现有的键）。现在的五种做法统一成一个组件 `DtTabs` 和一个组合函数 `useTabQuery`。
7. 吸顶：页面的标签页和筛选胶囊滚动时吸在顶栏下面。
8. 旧网址全部保留跳转。

## 5. 页面通用模式（P2 定组件，P3~P8 套用）

1. 页面骨架：顶栏 → 区域头图（只在区域首页，≤ 88px，叠关键数字，如“厨塔 · 第 12 层 · 声望 340”）→ 吸顶的标签页和筛选胶囊 → 内容 → 需要时底部操作条或弹出面板。
2. 四种行，都是细线分隔，不再一行一张卡片：
   - 操作行 `.dt-item`：小图形、名称、信息行，右侧一个按钮或一行状态字（如“缺 2 样”）。
   - 只读行 `.dt-feed`：时间加文字，13px。
   - 键值行 `.dt-kv`：左标签右数值，数字等宽。
   - 导航行 `.dt-nav-row`：图标、名称、当前值、右边 `›`。
3. 分组卡片 `.dt-card`：一个区块一张卡片，里面装多行（像 iOS 设置页）；卡片间距 8px。
4. 网格：橱柜等库存 4 列；首页设施 3 列（问题记录 577）；小镇页 3 列。
5. 表格：数字等宽右对齐；超过 4 列在手机上转置成每项一行。
6. 数量输入：固定宽度的数字框统一换成步进器 `DtStepper`（− 数字 +）。长表单（期货下单、交易所挂单、大宗出价）放进底部面板 `DtSheet`。
7. 确认：浏览器自带的确认框统一换成底部确认面板。提示保留底部胶囊（问题记录 545），换新样式。
8. 空状态：插画 + 为什么空 + 去哪里获得。加载：占位骨架行，不写“加载中…”。
9. 酒吧小游戏：保留各自的玩法画面，统一外框、按钮、结果展示，配图形。
10. 后台：只换令牌和整理版面，不进 i18n，不做图形。

### 6.2 分支和协作

- 不做叠起来的 PR：每批从最新的 main 开，上一批合并后再开下一批。本文和实施计划先提交在 `feat/ui-redesign`，P1 在这个分支上接着做（开工前合入最新 main）。
- 另一个代理在 P1 合并后写的新页面要遵守：不写裸色值，只用令牌；用第 5 节的行和卡片；图形用 `DtArt`。P2 合并后，标签页用 `DtTabs`/`useTabQuery`，路由写 `meta.parent`、`meta.section`、`meta.title`。
- 每个 PR 一条五种语言的更新记录（玩家能看到的改动）。

### 6.3 沿用的约定

- 文案：简中用半角括号、“: ”和“, ”；法文窄空格写 ` ` 转义；英法西数量用 `plEn`/`plFr`/`plEs`；繁中最后跑 `pnpm -F @dt/web i18n:tw`，不格式化。
- 新图标字体符号要跑 `pnpm -F @dt/web icons`；改了配置先 `pnpm -F @dt/config build`。
- 推送前跑 lint、`prettier --check .`、类型检查（分包看退出码）和四个包的测试。
- `问题记录.md`、`apps/web/e2e/_*.cjs`、`shots/` 不提交。
