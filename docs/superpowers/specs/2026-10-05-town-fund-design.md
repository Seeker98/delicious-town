# 小镇发展基金 设计（货币回收 240-2 第三项）

- 日期：2026-10-05
- 来源：问题记录 240——“小镇发展基金（存一定天数冻结，到期返还本金+小额利息+限定勋章等，提前提取惩罚性扣款）”。
- 用户已定：
  - 方向 A（240-1）时同意不给利息：利息等于凭空发钱，和回收银币的目标相反。
  - 方案 2：到期返还 90% 本金，加一枚带加成的限定勋章。
  - 每一期只能参加一个基金，同一时间最多一枚基金勋章，不叠加。
  - 第 1~5 节的档位、存期、比例、页面、测试。
- 不涉及菜园。

## 1. 玩法

- 小镇页加一个“发展基金”标签。
- 每家店同一时间只能有一笔存款（“一期一个基金”）。这一笔领取或提前取出之后，才能存下一笔。
- 三档，存期都是 7 天：

  | 档 | 存入 | 到期领回（90%） | 勋章（领取后 7 天有效） |
  |---|---|---|---|
  | 铜 | 100 万 | 90 万 | 基金铜勋章：经验 +5% |
  | 银 | 300 万 | 270 万 | 基金银勋章：经验 +10% |
  | 金 | 1,000 万 | 900 万 | 基金金勋章：经验 +15% |

- 到期后玩家点“领取”：拿回 90% 本金，得到对应勋章。到期不领就一直留着，什么都不会丢。
- 提前取出：只退 70%，没有勋章。到期后不能再提前取出，只能领取。
- 勋章不叠加：领新勋章时，去掉身上其他还没到期的基金勋章。按默认数值，下一枚最早在上一枚到期时才拿得到；这一条是保险，以后改了存期或勋章有效期也不会两枚同时生效。
- 存入金档时发一条小镇新闻：“某店向小镇发展基金存入 1,000 万银币”。
- 勋章只加经验、不加银币：加银币等于又开一个产出口，会抵消回收；加经验只让成长稍快，不违反 240-1“成长不变慢”的目标。

## 2. 回收效果

- 按时存满：每笔回收 10%，比如金档回收 100 万，换来一周经验加成。
- 提前取出：回收 30%。
- 所有金额、比例、存期、勋章都写在区服数值里，可以按区服调。

## 3. 数据和接口

### 3.1 配置

- 新数据文件 `packages/config/data/game/fund.json`：三枚勋章的道具（93101 铜、93102 银、93103 金）。每枚写名字、说明、加成（`expRate` 0.05 / 0.10 / 0.15）和有效小时数 168，构建成“荣誉”类道具（和其他限时勋章同一种），不出售。
- 区服数值 `tuning.fund`：

  ```
  fund: {
    days: 7,             // 存期（天）
    returnRate: 0.9,     // 到期领回的比例
    earlyRate: 0.7,      // 提前取出退回的比例
    tiers: [
      { key: 'bronze', coin: 1000000, medal: 93101 },
      { key: 'silver', coin: 3000000, medal: 93102 },
      { key: 'gold', coin: 10000000, medal: 93103, news: true }
    ]
  }
  ```

- 构建检查，后台保存区服数值时也跑同一套：
  - `0 < earlyRate ≤ returnRate ≤ 1`，`days ≥ 1`；
  - 档位 key 不重复；
  - 勋章是“荣誉”类道具。
- `setting_docs.json` 写说明。
- 区服功能开关加 `fund`，默认开；关掉时接口报“功能关闭”，标签不显示。
- 勋章名字、说明写简中、英、法、西；繁中自动生成。

### 3.2 数据库（新迁移）

`fund_deposit` 表：

| 列 | 说明 |
|---|---|
| `id` | 主键 |
| `shard_id`、`rest_id` | 哪家店（删店时一起删） |
| `tier` | 档位 key |
| `coin` | 存入的银币 |
| `started_at`、`matures_at` | 存入、到期时间（`matures_at` 按存入时的 `days` 算好写进来，之后改区服数值不影响已有存款） |
| `status` | `active` 存着 / `claimed` 已领 / `withdrawn` 已提前取出 |
| `settled_at`、`returned` | 领取或取出的时间、退回的银币 |
| `medal` | 存入时这一档的勋章（同样写进来） |

部分唯一索引 `(rest_id) where status = 'active'`：同一家店只能有一笔“存着”的，两个请求同时存入时只有一笔成功。

### 3.3 服务端

- 新模块 `modules/fund`，全部操作走 `runOp`（锁店、记流水），功能开关 `fund`：
  - `GET /fund`：三档（金额、到期领回多少、勋章）、存期、比例、我当前的存款（没有为空）。
  - `POST /fund/deposit { tier }`：
    - 已有一笔存款报 `fund_active`；
    - 扣银币，不够报 `NOT_ENOUGH`、什么都不扣；
    - 写存款；
    - 金档发新闻 `fund.deposit`。
  - `POST /fund/claim`：
    - 没有存款报 `fund_none`，没到期报 `fund_not_mature`；
    - 退回 `floor(coin × returnRate)`；
    - 去掉其他基金勋章，发这一笔的勋章；
    - 状态改成 `claimed`。
  - `POST /fund/withdraw`：
    - 没有存款报 `fund_none`，已到期报 `fund_mature`（要走领取）；
    - 退回 `floor(coin × earlyRate)`；
    - 状态改成 `withdrawn`。
- 流水来源：`fund.deposit`、`fund.claim`、`fund.withdraw`。
- 返还比例按存入时还是领取时的区服数值算：按领取、取出时的（简单；运营调比例时立即生效）。存期和勋章按存入时写进存款的值，不受之后修改影响。

### 3.4 页面

- 小镇页“发展基金”标签：
  - 没有存款时：三张卡片，写存入、到期领回、勋章和加成、存期，按钮“存入”（弹确认框写明金额和规则）；钱不够的档按钮禁用并写明。
  - 有存款时：档位、金额、到期时间、倒计时。到期后显示“领取”；没到期显示“提前取出（只退 70%）”，点了弹确认框。
- 新闻 `fund.deposit` 的文案。
- 文案写简中、英、法、西，繁中自动生成。

## 4. 不做

- 利息；
- 快速模拟里的机器人存基金：只影响经验，不影响银币存量；
- 基金排行榜、全服累计捐款等展示（以后可以加）。

## 5. 测试

- **配置：** 真实数据的三档和三枚勋章；比例越界、档位重复、勋章不是“荣誉”类时报错。
- **迁移：** 同一家店两笔 `active` 存款被唯一索引挡住；`claimed` 的不挡。
- **服务端：**
  - 存入扣钱、写存款，银币不够什么都不扣；
  - 已有存款时不能再存；
  - 两个请求同时存入只成功一笔；
  - 金档发新闻，铜档、银档不发；
  - 领取：没到期不能领；到期退 90%、发勋章、勋章加成生效；不能重复领；
  - 领新勋章时去掉旧的基金勋章；
  - 提前取出：退 70%、没有勋章；到期后不能提前取出；
  - 改区服的存期不影响已有存款的到期时间；
  - 功能关闭时报功能关闭。
- **前端：** 没有存款、存着没到期、已到期三种状态；确认框；钱不够的档禁用。
