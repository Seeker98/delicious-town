# 猜酒杯改版设计（闯关，猜中可以收手）

- 日期：2026-10-07
- 状态：待用户审
- 来源：问题记录 427 第 5 项（猜酒杯改版）
- 替换：原来的猜酒杯（子项目 4C-1，`2026-09-30-subproject4c1-bar-design.md` §3.3）

## 1. 一句话

一局最多 4 轮，每轮桌上的杯子依次是 2、3、5、7 个，只有一个杯子里有骰子。每猜中一轮，可以拿走这一轮的奖励收手，也可以继续闯下一轮；猜错就什么都没有。

## 2. 用户已定的方向（2026-10-07）

| # | 问题 | 决定 |
|---|---|---|
| 1 | 玩法 | 一局闯关，猜中可以收手 |
| 2 | 每轮几个杯子 | 2、3、5、7 |
| 3 | 花费 | 每局 1 张神秘礼券，不再按连胜加价 |

## 3. 和原来的区别

| | 原来 | 改版 |
|---|---|---|
| 杯子 | 总是 3 个 | 每轮 2、3、5、7 个 |
| 一局 | 猜一次 | 最多 4 轮，猜中可以收手 |
| 花费 | 第 n 连要 n 张礼券 | 每局 1 张 |
| 胜率 | (1 + 幸运率) / (n + 1)，和桌上的 3 个杯子对不上 | (1 + 幸运率) / 杯子数，最高 95% |
| 奖励 | 第 n 连给奖励等级 n + 1 | 按闯到第几轮，见 §4 |
| 连胜 | 跨局连中几次 | 跨局“拿到奖励”的局数（§5） |

没有每日次数上限，和原来一样，靠礼券控制。

## 4. 规则

### 4.1 一局的流程

1. **开局**：点第 1 轮的某个杯子就开局。扣 1 张礼券，计每日活跃“酒吧娱乐”，同时猜这一轮。
2. **每一轮**：
   - 桌上有 2、3、5、7 个杯子（第 1~4 轮）。玩家点一个。
   - 服务端按胜率判猜没猜中，再定骰子在哪个杯子里：
     - 猜中就是玩家点的那个；
     - 猜错就从别的杯子里随机挑一个。
   - 前端翻开骰子所在的杯子。
3. **猜中**：
   - 不是最后一轮时，两个选择：
     - “收手”：拿这一档的奖励，本局结束；
     - “继续”：进下一轮，这一档的奖励作废。
   - 第 4 轮猜中就是通关，直接拿最后一档。
4. **猜错**：本局结束，什么都没有。
5. **中途离开**：
   - 局面存在服务端，刷新后能接着选（`bar_round`，`game = 'cup'`）。
   - 有一局没结束时，不能开新局；点杯子就是接着这一局。

### 4.2 奖励

| 闯过 | 杯子 | 累计概率（不算幸运） | 奖励 | 新闻 |
|---|---|---|---|---|
| 第 1 轮 | 2 | 50% | 1 份奖励等级 2 的随机奖励 | – |
| 第 2 轮 | 3 | 16.7% | 2 份等级 4 | – |
| 第 3 轮 | 5 | 3.3% | 4 份等级 6 | 写 |
| 第 4 轮 | 7 | 0.48%（约 1/210） | 8 份等级 10 | 写，全服广播 |

- 随机奖励就是酒吧共用的那份：食材、物品、银币、经验，不出礼券，幸运照常翻倍。
- 新闻和广播每家店每天最多一条，两种合计，用每日计数 `bar.cup.news` 记。
- **为什么这样分档**：随机奖励的价值大致和等级成正比。把第 1 轮的奖励算作 1，四档大约是 1、4、12、40。
  - 第 1 轮猜中后继续：1/3 × 4 = 1.33，比收手划算。
  - 第 2 轮猜中后继续：1/5 × 12 ÷ 4 = 0.6，偏赌。
  - 第 3 轮猜中后继续：1/7 × 40 ÷ 12 = 0.48，纯赌运气。
  - 所以第 2 轮值得冲，第 3、4 轮是追新闻的豪赌。
- **收益对比**：按最划算的打法（第 1 轮猜中就继续，第 2 轮猜中收手），每张礼券平均约 0.67 份“等级 2 奖励”。原来第 1 连是 1 张礼券、50% 拿一份等级 2，约 0.5。改版后略高一点。

### 4.3 幸运

- 胜率 = (1 + 幸运率) / 杯子数，最高 95%。
- 和原来一样，幸运地猜中时，结果里写“幸运地”：随机数落在 1/杯子数 之上、但在胜率之内。

## 5. 连胜、排行、新闻

- `bar_state` 的 `cup_result` 和 `cup_times` 改记“局”。
  - 收手或通关算赢，猜错算输。
  - `cup_times` 是连续赢或连续输的局数，和划拳、转数字一样。
- 排行“酒吧连胜 / 连败”照旧读这两个字段，不用改。
- 新闻 `bar.cup` 的参数从 `{ times, lucky }` 改成 `{ round, cups }`。
  - 文案改成“在猜酒杯里连闯 3 关，从 5 个杯子里猜中了骰子”这类。
  - 以前的旧新闻没有 `round`，照旧按 `times` 显示原来的文案。

## 6. 数据

- 不加迁移。
- **局面**：`bar_round` 加 `game = 'cup'`，state 为 `{ round: number, won: boolean }`。
  - `round`：现在是第几轮，从 0 起。
  - `won`：这一轮已猜中，等玩家选收手或继续。
- **tuning**：`bar` 下新增

```
cup: {
  cost: 1,
  cups: [2, 3, 5, 7],
  maxRate: 0.95,
  tiers: [
    { awards: 1, level: 2, news: null },
    { awards: 2, level: 4, news: null },
    { awards: 4, level: 6, news: 'news' },
    { awards: 8, level: 10, news: 'broadcast' }
  ]
}
```

  - 校验：`cups` 和 `tiers` 一样长；每个杯子数至少 2、最多 10。
  - `news`：`null` 不写；`news` 写新闻 `bar.cup`；`broadcast` 写全服广播 `bar.cup.big`，和一番赏大赏一样进首页广播位，在 `BROADCAST_STYLE_NEWS` 里登记。
  - 原来的 `cupNewsStreak` 不再用了，从数值里删掉。

## 7. 接口

| 方法 | 路径 | 请求 | 返回 |
|---|---|---|---|
| GET | `/bar` | – | `BarDto.cup`：上一局结果、连续局数、每局花费、每轮杯子数、每档奖励、进行中的局 |
| POST | `/bar/cup/guess` | `{ cup }` | `CupDto`。没有局时先开局扣礼券；`cup` 是这一轮的杯子编号，从 0 起 |
| POST | `/bar/cup/stop` | – | `CupDto`。收手拿奖励 |
| POST | `/bar/cup/next` | – | `CupDto`。继续下一轮 |

- **`CupDto`**：
  - `round`、`cups`：这一轮几个杯子；
  - `won`：这一轮猜中了，等玩家选；
  - `last`：`{ pick, ball, win, lucky }`，最近一次猜的结果；
  - `result`：`'stop' | 'clear' | 'lose' | null`；
  - `awards`：结束时拿到的奖励。
- **错误**：

| 情况 | 错误 |
|---|---|
| 这一轮已猜中、还没选就再猜 | `invalidState('cup_decide')` |
| 没有猜中就收手或继续 | `invalidState('cup_not_won')` |
| 没有局 | `invalidState('no_round')` |
| 杯子编号越界 | `badInput('cup')` |
| 礼券不够 | 原有的 `NOT_ENOUGH` |

- 原来的 `POST /bar/cup` 删掉。网页和服务端同时发布，旧网页在发布那几分钟里点猜酒杯会报错，刷新就好。

## 8. 前端

- 规则一行：每轮几个杯子、猜中可以收手或继续、猜错什么都没有。
- 四档奖励写成一张小表：第几轮、几个杯子、奖励。只写“几份奖励”，不写等级数字，大奖档标“上新闻”。
- **杯子**：
  - 按本轮杯子数排，一行最多 5 个，`minmax(0, 1fr)`。
  - 点一个就猜；猜完翻开骰子所在的杯子，标出“你选的”。
- **猜中、不是最后一轮时**：
  - 写“猜中了！收手拿【这一档】，还是继续闯第 n 轮（m 个杯子）？”；
  - 两个按钮：“收手”“继续”。
- **结束**：写拿到的奖励（多份时逐份列出），或“猜错了，骰子在 x 号杯”；下面是“再来一局”。
- 连胜行照旧：“当前 n 连胜”。
- **读屏**：固定的播报区，念每次猜的结果和结束的结果。杯子按钮的标签写编号和状态。
- **出错**：局没了回到开局；别的错误留在当前这一局，再重新读。
- 雯姐里关于猜酒杯的台词要检查，提到“第 n 连要 n 张礼券”的要改掉。

## 9. 测试

**服务端**
- 胜率函数：(1 + 幸运) / 杯子数，最高 0.95。
- 开局：
  - 没有局时猜就开局，扣 1 张礼券；
  - 有局时猜不扣礼券；
  - 礼券不够不扣、不建局。
- 猜：
  - 猜中，`ball` 就是选的杯子；
  - 猜错，`ball` 是别的杯子；
  - 越界被拒；
  - 已猜中、没选就再猜，被拒。
- 收手：发这一档的份数和等级，局面删掉，连胜加一。
- 继续：进下一轮，杯子变多；没猜中时继续被拒。
- 第 4 轮猜中：通关，发最后一档，写新闻和广播。
- 猜错：没有奖励，连败加一。
- 新闻：第 3 轮收手写一条；同一天第二次不写。
- 连胜：跨局累计赢、输。
- 排行“酒吧连胜”能读到。
- 数值校验。

**前端**：面板测试覆盖开局猜、猜中后的两个按钮、继续后杯子变多、收手、通关、猜错、读屏播报、出错时的处理。

**端到端**：猜第 1 轮，猜中就收手，猜错就再来一局，直到拿到一次奖励（最多试 10 局）。
