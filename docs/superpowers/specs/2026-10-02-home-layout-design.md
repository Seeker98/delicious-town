# 首页排版重做（问题记录 280）

## 1. 背景

首页的元素一块块往下堆：活动横幅、等级经验、四个快捷图标、资源、签到、主线任务、新闻、设施、经营开关、一长串生效的加成。每块的边框、字号、间距各不相同，显得凌乱。

用户提供了两个正在运营的复刻版首页作参考（`data/antchen_mainpage.html`、`data/xlu_mainpage.html`）：

- antchen：图标化的卡片，分成餐厅状态、设施、广播、导航网格几大块；
- xlu：纯文字，一行一项状态，每行右边直接跟操作链接，功能入口集中成几行文字链接。

## 2. 用户确认的裁定

1. 第一屏放：餐厅状态、今日待办、小镇动态。
2. 布局选 A：三张卡，下面是设施、经营开关；生效的加成默认折叠成一行摘要。
3. 快捷入口保留「厨具与加点 · 仓库 · 商店」一行小链接；"任务"并进待办卡的"今日活跃"。

## 3. 布局

**顶部**：店名行（天气、切换区服）不变。重要公告横幅、嘻哈男孩卡片、痞老板提示只在有事时出现，放在最上面。

**餐厅卡**：

- 街道 · 星级 · 等级，停业标记，个性图标；
- 经验条；
- 银币、钻石、体力、声望两列；油一行，右边「加满」；
- 上一轮收益一行（客人一行，超出省略），收益记录 ›、楼层餐桌 ›；
- 底部小链接：厨具与加点 · 仓库 · 商店。

**今日待办卡**：一行一件事，右边是操作（`.dt-todo-row`）。

- 每日签到 [签到] / 今天已签到；
- 主线任务 进度 [领奖]；
- 今日活跃 N 任务 ›；
- 限时活动 N 个进行中 查看 ›（原来的活动横幅）；
- 蹭饭中 [结束白食]（只在蹭饭时出现）；
- 新手看这里 → 游玩指引（10 级以下）。

**小镇动态卡**：广播和新闻，和原来一样。

**下方**：设施网格、经营开关不变；生效的加成用 `<details>` 折叠，摘要写"N 项：来源名、来源名、来源名 等"，点开是原来的分组列表。

## 4. 测试

- 三张卡的顺序和每张卡里的元素；
- 快捷入口只剩三个；
- 今日活跃一行和链接；
- 生效的加成默认折叠；
- 原有元素的 `data-testid` 全部保留，现有测试和 e2e 照常通过。
