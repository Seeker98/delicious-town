# 全游戏文字链接统计和统一（问题记录 451）

- 日期：2026-10-07
- 范围：网页 `apps/web/src` 下的 `.vue`，不含管理后台（另有 45 处）和菜园（菜园不考虑）。
- 基础：#189（问题记录 445）已经给首页定了规范，这次推到全游戏。

## 1. 统计

脚本把 `<RouterLink>`、`<a>`、带 `btn-link` / `dt-link-btn` 的 `<button>` 都找出来，一共 **132 处**：

| 写法 | 处数 | 说明 |
|---|---|---|
| 没加任何样式的 `RouterLink` / `<a>` | 39 | Bootstrap 默认：品牌色、**带下划线**、没有箭头 |
| 加了零散样式的（`small`、`fw-bold`、`text-reset` 等） | 33 | 有的带下划线、有的不带；返回链接有的自己写“‹” |
| `btn btn-link` 按钮 | 16 | 样子像链接、**带下划线**、按钮的内边距，比别的文字链接大一圈 |
| 菜单、标签页、底栏 | 15 | 不是文字链接 |
| `.dt-go`（#189 定的） | 12 | 只在首页：品牌色、无下划线、末尾一个“›” |
| 整行 / 整块可点 | 8 | 不是文字链接 |
| 按钮样子的链接（`btn`） | 9 | 不是文字链接 |

另外文案里自己写了箭头的有 8 处，其中只有 2 处是链接：“有 n 点可加 →”“厨具与加点 →”（餐厅信息页）。其余是路径说明（“更多 → 其他 → 兑换码”）或变化（“1 个 → 2 次”“→ 下一级名字”），不是链接。

**乱在哪**：同样是“去别的页面”，首页的不带下划线、带“›”，别的页面带下划线、不带箭头；返回链接有的写“‹”、有的不写；“重发”“刷新”“取消”这类本页操作，有的是带下划线、带内边距的 `btn-link`，有的是 `<a href="#">`，首页的签到、加油又是 `.dt-link-btn`。

## 2. 规范

| 种类 | 例子 | 写法 | 样子 |
|---|---|---|---|
| 去别的页面的入口 | 去广场、神殿、教室、论坛、玩法攻略、注册新账号、进入小镇 | `RouterLink` + `.dt-go` | 品牌色、无下划线、末尾“›” |
| 返回上一级 | 返回论坛、Wiki 首页、返回、协会、返回登录 | `RouterLink` + `.dt-back` | 品牌色、无下划线、开头“‹” |
| 句子、列表里的名字 | 店名、道具名、食材名、街道名、NPC 名、#楼层 | 照旧不加类 | 品牌色、无下划线、不加箭头（一列名字每个都带“›”太乱） |
| 本页操作 | 重发、刷新、取消、回复、删除、关掉、重试、展开 / 收起 | `<button>` + `.dt-link-btn`；删除、撤单再加 `text-danger` | 和链接一样的字、没有内边距、不加箭头 |
| 不是文字链接 | 底栏、顶栏、标签页、整行可点、按钮样子的链接 | 不动 | 不动 |

- 全站链接去掉下划线（`a { text-decoration: none }`），名字链接靠品牌色区分。
- 文案里不写箭头，箭头由样式加，读屏不读。
- 路径说明和变化里的“→”保留。

## 3. 改了哪些

- **`.dt-go`**（去别的页面）：
  - 登录页的注册、忘记密码、Wiki；注册页的去登录；重设密码页的去登录；验证邮箱页的进入小镇；
  - 选区服页的账号、游玩指引；我的账号的邀请码；天气页的去广场；
  - 小镇的论坛；特色菜页的神殿、教室；餐厅信息页的加点、厨具（去掉文案里的“→”）；
  - 食谱页搬街提示的链接；游玩指引页的 Wiki 提示；Wiki 首页的玩法攻略、开放接口。
- **`.dt-back`**（返回）：论坛帖子的返回论坛；协会 NPC 页的协会（去掉写死的“‹”）；Wiki 各页的返回、Wiki 首页；忘记密码页的返回登录。
- **`.dt-link-btn`**（本页操作，原来是 `btn btn-link` 或 `<a href="#">`）：
  - 神殿克拉肯的刷新、试炼的刷新；
  - 我的账号、选区服页的重发验证邮件；
  - 食谱页关掉搬街提示；交易所撤单；
  - 论坛的回复、删除、取消回复；特色菜的取消；协会 NPC 的重试；举报；
  - 事件合约的展开 / 收起已结束；菜场竞猜的展开 / 收起。
- **不动**：底栏、顶栏、标签页、公告、邮件标题、顶栏时间（整块可点、`text-reset` 的）。

## 4. 拿不准、留给用户看的

- **名字链接不带下划线以后**，只靠颜色和正文区分。品牌色和正文对比明显，手机上没问题；如果要照顾色弱，可以只给句子中间的名字链接加虚线下划线。
- **页面顶上的返回链接**和顶栏左上角的返回箭头有点重复（论坛帖子、Wiki 详情、协会 NPC），这次只统一样子，没删。
- **举报**保留灰色（`text-muted`），不用品牌色：不想让它显眼。
