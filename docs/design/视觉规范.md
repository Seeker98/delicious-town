# 视觉规范

- 日期：2026-10-01
- 来源：问题记录第 100 条，要求从排版、留白、视觉层级、色彩、动效、微交互、响应式几方面整体自检。
- 适用范围：所有页面。本次先用到首页、小镇、商店、仓库；酒吧在扩展三个新游戏时一起改，其他页面以后改动时顺手跟上。
- 实现位置：样式写在 `apps/web/src/styles/main.css`，组件里不写 `<style>`，也不写 `style="..."`。

## 1. 自检结论（2026-10-01，手机宽度 390px 截图）

| 问题 | 例子 |
|---|---|
| 颜色两套 | 顶栏、区块标题是品牌橙色，按钮、链接、标签页却是 Bootstrap 默认蓝色 |
| 页面标题没有层次 | "小镇""酒吧"只是一行普通字，和正文差不多 |
| 列表行写法不统一 | 商店是"名称 + 信息行 + 右侧操作"，小镇兑换是竖着堆四行，仓库的按钮宽度跟着价格变 |
| 只读列表留白太大 | 新闻每行最小高度 42px，一屏只有十几条 |
| 操作按钮位置不固定 | 小镇的"聊天""摇一摇"紧贴在说明文字后面，没有靠右对齐 |
| 内联样式 | 宽度、字号散落在模板的 `style` 里，改一处要找很多地方 |

## 2. 颜色

| 用途 | 值 |
|---|---|
| 品牌色（装饰：顶栏、区块标题色条、图标） | `--dt-primary` `#d9480f`（白底对比度 4.30，不用来写字） |
| 品牌色·文字（主按钮底色、链接、选中的标签页和胶囊） | `--dt-primary-ink` `#c2410c`（白底对比度 5.18） |
| 品牌色浅底（选中、悬停） | `--dt-primary-soft` `#fff4e6` |
| 页面底色 | `--dt-bg` `#fff4e6`；内容区白色 |
| 正文 | `#212529` |
| 次要文字（信息行、时间） | `--dt-muted` `#6c757d`（白底对比度 4.69） |
| 分隔线 | `--dt-line` `#f1f3f5` |
| 成功 / 有利 | 绿 `#2b8a3e`，浅底 `#ebfbee` |
| 危险 / 不利 / 不能操作的原因 | 红 `#c92a2a`，浅底 `#fff5f5` |

Bootstrap 的 `primary` 统一改成品牌色（按钮、链接、标签页、勾选框、开关、聚焦光圈），不再出现默认蓝色。Bootstrap 的 `danger`、`success` 也按上表覆盖（`--bs-danger`、`--bs-success`），危险按钮（丢弃、删除）用规范红并配图标，和品牌橙拉开。禁用的按钮一律变灰（主按钮灰底白字，描边按钮灰字灰边），不用淡化的品牌色。所有用来写字的颜色在白底上对比度至少 4.5（`styles/theme.test.ts` 检查）。

## 3. 字号和层级

| 层级 | 写法 | 规格 |
|---|---|---|
| 页面标题 | `.dt-page-title`（或直接写 `<h5>`，全局同样规格） | 18px，粗 600；右侧可放一行次要信息（如持有礼券） |
| 区块标题 | `.dt-section` | 15px，粗 600，左侧 3px 品牌色条，上方留 12px |
| 卡片、列表条目标题 | `.dt-card-title`、`.dt-item-title` | 14px，粗 600；不要在卡片里用 `<b>` 当标题（会继承 16px，显得粗大，问题记录 278） |
| 正文 | Bootstrap `small` | 14px |
| 信息行 | `.dt-meta` | 12px，次要文字色 |
| 标签、角标 | `.dt-chip`、`.dt-tag` | 11~12px |

一屏里最多三层字号：标题、正文、信息行。

## 4. 间距

内外边距、间隔以 4 的倍数为主：4、8、12、16px。问题记录 439（提高信息密度）以后，几个高频容器允许用 2、3、6、10px：页面标题上下 2 / 6px、待办行上下 2px、列表行上下 3px、卡片内边距 6px 10px、卡片之间 6px。线宽和圆角不受这条限制：1px 边框和分隔线、3px 的区块标题色条和飞镖准星宽度、6px / 8px 圆角。

- 页面左右内边距：8px。
- 区块之间：12px（区块标题上方）。
- 列表行上下：3px，行高至少 40px（问题记录 439 从 44px 降下来；整行可点的列表也有 40px，超过 WCAG 2.2 要求的 24px）。
- 按钮之间：4px。

## 5. 组件

**列表行** `.dt-item`（可操作的列表：商店、仓库、兑换、NPC 等）
- 左边是主体 `.dt-item-main`：第一行名称 `.dt-item-title`，超长截断；第二行 `.dt-meta` 写数量、价格、限制等；需要时第三行写说明，默认只显示一行，点名称展开。
- 右边是操作区 `.dt-item-actions`：固定宽度，数量框 `.dt-qty`（64px）加一个按钮，按钮文字不放会变长的数字。
- 行高最少 40px，行与行之间用浅分隔线。
- 不能操作时，按钮变灰，原因用红字写在信息行里，不弹窗。

**紧凑行** `.dt-feed`（只读列表：新闻、流水、日志）
- 不设最小高度，上下 3px，13px 字，时间在前、用次要文字色。

**卡片** `.dt-card`（一块独立内容：首页的小镇新闻、星愿、游戏区）
- 白底，1px 浅边框，8px 圆角，内边距 6px 10px；卡片之间 6px。

**标签页**
- 页面一级分区用 `nav-tabs`；标签页里面再分类用 `.dt-pills`（小号胶囊，横向排一行）。
- 一级标签页不换行：英法西文放不下时横向滑动（2026-10-04 自检）。
- 筛选（等级、类型、在售等）一律用 `.dt-pills`，胶囊可以是 `<a>` 也可以是 `<button>`；不用灰色按钮组。

**名字截断**
- 列表行的名称超长截断（一行）。
- 网格、方块里的名字（橱柜食材、活跃项、设施位）最多两行再截断（`.dt-clamp2`），免得名字后半截的关键字（如万能食材的等级）被截掉；橱柜方块最多三行。

**提示块** `.dt-note`：品牌浅底、浅边框，用于说明性的提示（如一番赏月度主题）；不用 Bootstrap 的 `alert-info`（青色不在配色里）。

**空状态** `.dt-empty`：居中、次要文字色，说明为什么空、去哪里获得。

## 6. 动效和微交互

- 按钮、可点的方块：按下时缩到 97%（80ms），松开回弹，让点击有反馈。
- 悬停（桌面）：可点的方块浅品牌底色。
- 结果提示沿用底部 toast；结果数字变化不做大动画。
- 尊重系统"减少动态效果"设置：开启时不做缩放。

## 7. 响应式

- 内容最宽 720px，最窄按 360px 设计。
- 列表行在 360px 宽时，主体文字截断，操作区不换行。
- 一排里是下拉框或输入框加按钮时：输入框用 `.dt-shrink`（占剩下的宽度、可以收窄），按钮 `flex-shrink-0`；英法西文的选项名长，不这样会把按钮挤出屏幕（视觉自检第二轮）。
- 超过四列的数值表在手机上转置成每项一行（例如厨具属性表），不靠左右滑。
- 剩余时间一天以上写天和小时（“剩余 15 天 8 小时”），不写几百小时。
- 英法西文案里“数字 + 名词”一律用 `plEn` / `plFr` / `plEs`（`i18n/helpers.ts`）选单复数，名词后面紧跟的形容词、动词一起放进去；不写“(s)”。法文 0 和 1 都用单数。
- 网格（快捷入口、设施、橱柜）在手机上 4 列，不随宽度变化。
