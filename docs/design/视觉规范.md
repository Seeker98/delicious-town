# 视觉规范

- 日期：2026-10-11（第二版，取代 2026-10-01 的第一版）
- 来源：[界面全面改版设计](../superpowers/specs/2026-10-10-ui-redesign-design.md) P1
- 实现位置：`apps/web/src/styles/` 三层——`tokens.css`（令牌，只有这里写色值）、`base.css`（Bootstrap 接管和控件）、`main.css`（`dt-*` 组件和页面）。组件里不写 `<style>`，也不写带颜色的 `style="..."`。
- 适用范围：所有页面。P2 以后的批次按设计文档第 5 节的通用模式改版面，改到哪里就让哪里符合本规范。

## 2. 深色模式

- 设置在“我的账号 → 外观”：跟随系统（默认）/ 浅色 / 深色，存本地存储 `dt_theme`，只跟设备走。
- `index.html` 的内联脚本在渲染前给 `<html>` 写 `data-theme` 和 `data-bs-theme`，不会先白后黑；运行中由 `utils/theme.ts` 切换和跟随系统。
- 深色下不用阴影，靠 `bg` → `surface` → `surface-2` 三档底色分层次。
- 模板里写死的浅色类（`bg-light`、`bg-white`、`text-dark`、`btn-light`、`text-bg-light`）在 `base.css` 里已接到令牌上，深色下也是深底浅字；新代码不要再用它们。
- 新写的样式在两种模式下都要截图看过。

## 3. 字体和层级

- 字体：系统无衬线 `--dt-font-sans`；读的页面（小镇日报、资料库、更新记录）的标题可用衬线 `--dt-font-serif`。不加载网络中文字体。
- 数字等宽：全局 `font-variant-numeric: tabular-nums`。

| 层级               | 写法                                                             | 规格                           |
| ------------------ | ---------------------------------------------------------------- | ------------------------------ |
| 页面标题           | 顶栏 `.dt-header-title`（路由 `meta.title` 或 `usePageTitle()`） | 17px，600，一行截断            |
| 区块标题           | `.dt-section`                                                    | 15px，600，左侧 3px 紫色条     |
| 卡片、列表条目标题 | `.dt-card-title`、`.dt-item-title`                               | 14px，600                      |
| 正文               | Bootstrap `small`                                                | 14px                           |
| 信息行             | `.dt-meta`                                                       | 12px，次要文字色               |
| 标签、角标         | `.dt-chip`、`.dt-tag`、`.badge`                                  | 11~12px；最小 11px（测试检查） |

一屏里最多三层字号：标题、正文、信息行。

## 4. 间距、圆角、阴影

- 间距按 4px 网格：`--dt-space-1 … 6` = 4、8、12、16、20、24px。问题记录 439 的紧凑值保留：列表行上下 3px、整行可点的行至少 40px、卡片内边距 6px 10px、卡片之间 6px。
- 圆角：`--dt-radius-xs` 4（标签）、`--dt-radius-sm` 10（输入框、提示块、方块）、`--dt-radius-md` 14（卡片、面板、弹窗）、`--dt-radius-pill` 16（按钮、胶囊；长文案折两行时是圆角矩形，不变大椭圆）。
- 阴影只给浮起来的东西（提示胶囊、弹窗、底部面板）：`--dt-shadow-float`。卡片用 1px 细线。

## 5. 能点和不能点

紫色只给能点的东西用。

| 元素                           | 写法                                     |
| ------------------------------ | ---------------------------------------- |
| 正文                           | 正文色，不能点                           |
| 强调（广播、重要数字）         | 加粗或琥珀色（`--dt-warning`），不用紫色 |
| 状态标签（未学、称号、进行中） | `.badge`（4px 圆角、浅底深字），不像按钮 |
| 整行去别处                     | 整行可点，右边一个灰色 `›`               |
| 句中链接（店名、玩家名）       | 紫字，不带下划线（P2 起加点状下划线）    |
| 本页操作                       | 按钮（见下）                             |
| 危险操作（丢弃、删除）         | 红描边按钮 + 图标                        |

按钮和现有类名的对应：

| 按钮                               | 类名                           | 样子                       |
| ---------------------------------- | ------------------------------ | -------------------------- |
| 主操作（一处只放一个）             | `btn btn-primary`              | 实心紫                     |
| 次要                               | `btn btn-outline-primary`      | 浅紫底、紫字（不再是描边） |
| 中性（切换区服、全部卸下）         | `btn btn-outline-secondary`    | 浅灰底、细边、正文色       |
| 纯文字（取消、签到这类本页小操作） | `dt-link-btn` / `btn btn-link` | 紫字、无底                 |
| 危险                               | `btn btn-outline-danger`       | 红描边                     |

- 绿色、黄色按钮（`btn-success`、`btn-warning`）不在四种里，P1 先按语义浅底显示，P3~P8 改到哪里换到哪里，新代码不要用。
- 不能操作：按钮变灰（`--dt-disabled-bg` 底、`--dt-disabled-text` 字），原因用红字写在信息行里，不弹窗。

## 6. 控件

- **一级标签页** `nav-tabs`：下划线式，选中的字是正文色加粗，下面一条 2px 紫线；切换时下划线滑过去（`utils/tabsScroll.ts` 写位置，`base.css` 的 `.nav-tabs::after` 画线）。不换行，放不下横向滑动，右边渐隐。
- **筛选胶囊** `.dt-pills`：细边胶囊，选中是深色实心（正文色底），故意不用紫色，和“操作”分开。
- **徽章** `.badge`：浅底深字；未读数圆点 `badge rounded-pill bg-danger` 保持实心。
- **提示块** `alert-*`：浅底深字、无边框、10px 圆角；`alert-info` 是紫水晶浅底。说明性的提示用 `.dt-note`。
- **输入框、下拉框**：`surface-2` 底、10px 圆角，聚焦时紫边加浅紫光圈。
- **勾选框、开关**：选中紫色。
- **进度条**：浅紫轨道、紫色填充。
- **焦点**：键盘焦点一律 2px 紫色外圈（`:focus-visible`）；标签页里的焦点框画在标签里面。

## 7. 动效

- 曲线：`--dt-ease-out`（出现、反馈）、`--dt-ease-drawer`（底部面板）。不用 `ease-in`。
- 时长：按下 120ms、颜色 150ms、下划线和下拉 200ms、面板 280ms；界面动效一律 ≤ 300ms。
- 按下：按钮、胶囊、`.dt-tap` 缩到 97%。
- 只动 `transform`、`opacity`（颜色过渡可以）；不写 `transition: all`；不从 `scale(0)` 出现。
- 悬停效果只写在 `@media (hover: hover) and (pointer: fine)` 里（触屏点一下不会粘住悬停色）。
- 系统开了“减少动态效果”：不缩放、下划线不滑。
- 结算数字、频繁刷新的数值不加动画。

## 8. 图形

- 两个家族：
  - **界面图标**（单色紫调）：`src/art/ui/*.svg`，名字以 `nav-`、`place-`、`me-`、`fac-`、`slot-`、`sec-` 开头。只用 `currentColor`：描边 2px 圆头，需要浅色调的形状写 `fill="currentColor"`，深浅由外层 CSS 的 `fill-opacity` 给（普通 0.18，选中 0.4），不写色值和 `fill-opacity`。
  - **内容图形**（无描边扁平）：`src/art/content/*.svg`，名字以 `res-`、`food-`、`goods-`、`npc-`、`empty-` 开头。固定色值平涂，细节用半透明深线或白线。
- 都是 48×48 的 viewBox，不能有脚本、样式、外链、图片、文字；必须是合法 XML（`art.test.ts` 检查，一处写错会让雪碧图里后面的图形全部不显示）。
- 改了图形跑 `pnpm -F @dt/web art`，生成 `src/art/generated/` 下的两张雪碧图和名字表（提交进仓库）。
- 页面里用 `<DtArt name="…" :size="24" />`；只有图标、没有文字时加 `label`（读屏会读）。
- 体积上限：两张雪碧图压缩后 ≤ 25KB，加上头图 ≤ 120KB（测试检查）。
- 开发环境的图库 `/dev/art`：浅色、深色并排看所有图形；新图先给用户过目再接进页面。
- 16px 以下的小符号（`›`、关闭、对勾）继续用 Bootstrap Icons 子集（新图标要跑 `pnpm -F @dt/web icons`）。

## 9. 沿用第一版的规则

**列表行** `.dt-item`（可操作的列表：商店、仓库、兑换、NPC 等）

- 左边是主体 `.dt-item-main`：第一行名称 `.dt-item-title`，超长截断；第二行 `.dt-meta` 写数量、价格、限制等。
- 右边是操作区 `.dt-item-actions`：固定宽度，数量框 `.dt-qty`（64px）加一个按钮，按钮文字不放会变长的数字。
- 行高最少 40px，行与行之间用浅分隔线。

**紧凑行** `.dt-feed`（只读列表：新闻、流水、日志）：不设最小高度，上下 3px，13px 字，时间在前、用次要文字色。

**卡片** `.dt-card`：`surface` 底，1px 细线，14px 圆角，内边距 6px 10px；卡片之间 6px。

**名字截断**：列表行的名称一行截断；网格、方块里的名字最多两行（`.dt-clamp2`）；橱柜方块最多三行。

**文字链接**（[文字链接-2026-10-07.md](文字链接-2026-10-07.md)）

- 一律紫色、不带下划线（没加类的链接悬停、键盘选中时显示下划线）。
- 去别的页面用 `.dt-go`：末尾的“›”由样式加（读屏不读）。
- 在本页做一件事用 `<button class="dt-link-btn">`。
- 游戏内页面不再写返回链接：返回在顶栏（第 10 节）。`.dt-back` 只留给登录、忘记密码这类游戏外的页面。

**空状态** `.dt-empty`：居中、次要文字色，说明为什么空、去哪里获得。

**响应式**

- 内容最宽 720px，最窄按 360px 设计；宽屏保持单栏。
- 列表行在 360px 宽时，主体文字截断，操作区不换行。
- 一排里是下拉框或输入框加按钮时：输入框用 `.dt-shrink`，按钮 `flex-shrink-0`。
- 超过四列的数值表在手机上转置成每项一行。
- 剩余时间一天以上写天和小时。
- 英法西文案里“数字 + 名词”用 `plEn` / `plFr` / `plEs`，不写“(s)”；法文 0 和 1 都用单数。
- 网格（快捷入口、橱柜）在手机上 4 列；首页设施一行 3 个（问题记录 577）。

## 10. 导航（界面改版 P2a）

- **路由元数据**：每个游戏内路由写 `meta.section`（属于底部哪个入口：home、cookbooks、cupboard、market、friends、map）、`meta.title`（`(t) => 文案`）、`meta.parent`（上一级地址，或 `(to, back) => 地址`；`back` 是浏览器历史里的上一页，详情页用它回到原来的列表）。底部 6 个入口没有 `parent`。`router.test.ts` 检查每个游戏内路由都写全了。
- **顶栏** `AppHeader`：左边返回（回 `meta.parent`，不走浏览器历史；系统返回手势仍是浏览器后退）、当前页标题；右边游戏时间、邮件、“我”的头像（店名第一个字）。
- **页面标题**：页面里不再写 `<h5>` 标题行。动态标题（店名、帖子标题、NPC、天气）在页面的 `<script setup>` 里调 `usePageTitle(() => …)`，数据没读回来时顶栏先显示路由标题，离开页面自动清掉。
- **标题行右边原来的东西**（钱包、全部领取、相关链接、件数）：单独一行 `.dt-page-meta`，靠右、13px。
- **底部导航**：餐厅、食谱、橱柜、菜场、好友、小镇；按 `meta.section` 高亮（详情页也亮），图标是 `nav-*` 界面图标；区服关掉的功能不显示入口；入口名一行截断。
- **小镇** `/map`：买卖、玩乐、公共三组地方卡片（`.dt-place`：图标、名字、两行内的副标题），3 列。
- **我** `/me`、**帮助中心** `/help`：分组卡片 `.dt-group-card` 里放导航行 `NavRow`（图标、名称、可选的当前值、右边灰色 `›`）。新加“去别处”的整行入口一律用 `NavRow`。
- 入口叫什么，页面标题就叫什么（设计 §4.3）。

### 10.1 标签页和合并后的页面（界面改版 P2b）

- **一级标签**一律用 `DtTabs`（下划线式、吸顶在顶栏下面、放不下横向滑动；只有一个标签时不显示）+ `useTabQuery`：当前标签写在网址 `?tab=`（一番赏是 `?line=`，普通线不写），能分享、后退不丢；要记住上次看的就传 `storageKey`，优先级是网址 > 本地存储 > 第一个；标签列表会随区服开关变，网址里的值不在列表里时自动改成第一个。切标签只改 `tab`，别的参数（街道、页码、筛选）保留。
- 标签后面的数字用 `badge`（申请数、冰箱“新”），图标用 `#extra` 插槽（任务页的礼物）。
- **分区不超过两层**：一级是标签，再往下用下拉框（排行的子榜 `rank-board-select`）或分组标题，不再套第二排标签或按钮组。
- **合并后的页面**（旧地址都跳过去）：签到和今日活跃 → 任务页“今日”（`/rest/tasks?tab=today`，任务页不带参数时打开今日）；特色菜、进度一览 → 食谱页标签（`/cookbooks?tab=mc|progress`）；宝石 → 厨具页标签（`/rest/equip?tab=gem`）；盖乐瑞的基金、理财 → 小镇的“银行”（`/bank?tab=fund|wealth`）；新手兑换码、邀请好友 → 兑换码页，邮箱和游玩指引只放一条链接过去。
- **动态的一行**用 `FeedRow`（时间只写月日时分、统一文案、能点的去对方餐厅或帖子），首页和好友页一样；首页加 `dt-feed-1line` 截成一行。
- **叫法**：同一样东西各处一个名字（`i18n/naming.test.ts` 检查）——油壶扩容、切换区服、换食材、食谱（不写菜谱）、全部（不写更多）、限时折扣（原今日特价）、活动（原限时活动）；协会 NPC 页顶栏写“NPC 名 · 功能”。
