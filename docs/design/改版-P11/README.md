## 和设计图不一样的地方

- **顶栏**：和前几批一样，游戏里的页面顶栏右边还有时间、邮件和“我”。
- **页面底色**：和前几批一样是白底（设计图是浅紫底），卡片带细边；登录注册的输入框照设计图用浅紫底。
- **等级角标**：和菜场、橱柜一致，2 级绿、3 级以上紫（设计图里 5 级以上画成琥珀色）。
- **开店页街道那一行**：写“开在新手街, 以后想换一条街可以到协会搬家”。设计图写的“学会 100 道菜、升到 2 星后可以搬家”不对：搬家只要搬家卡和搬家费。
- **登录页的公告**：停服维护这类公告放在表单卡里标题上面（设计图没画）。注册、找回密码的人机验证在按钮上面。
- **切换区服**：“新开”是开服 30 天内的区服；开服第几天按开服日期算。没开店的区服里，“去开店”是整张卡点下去（整张卡是一个按钮）。
- **资料库首页报头**：右边只写“和游戏配置同步”，不写日期（接口没有配置日期）。
- **资料库搜索**：道具这一组也包括厨具（厨具也是道具）。
- **食谱词条**：名字下面写“食谱 · 菜系 · 口味…”，不再单写一段描述（描述就是菜系和口味）。厨具词条的“套装”是纯文字（没有套装页）。
- **玩法攻略**：只有“三种节奏”一节是两列表，每节小标题后面不写条数。
- **开放接口**：返回格式、缓存、跨域、频率、不包含分成五小节（设计图合成一节）；接口表里路径从 `/open` 写起。
- **游玩指引**：每天的事项先列 6 项，下面“还有 3 项 · 展开全部”。
- **更新记录**：“新”字只标比上次来时新的条目；从没看过时只标最新一天。真实条目很长，一天一栏照样排。
- **邀请好友**：法文、西文的“复制注册链接”写成短的“复制链接”，不然按钮折三行。
- **筛选胶囊**：资料库列表的筛选胶囊沿用游戏里现有的样式（比设计图矮一点）。
- **友情链接没有链接时**：用游戏里通用的空状态（图 + 两行字），不套卡片。
