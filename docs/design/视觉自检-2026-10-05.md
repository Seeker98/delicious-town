# 视觉自检第二轮（2026-10-05，问题记录 100，质量期 ④）

- **范围**：玩家页面 51 个，加上页面里的一级标签页，每种语言 75 个画面。
  - 手机宽度 393px：五种语言都跑；
  - 360px（最窄的常见手机）：简中、法文、西文。
- **方法**：Playwright 用新注册的号（60 级、4 星，仓库里放了常见道具），逐页截整页图，并自动检查：
  - 页面有没有横向溢出；
  - 有没有元素伸出屏幕右边（不算本来就能左右滑的容器）；
  - 有没有文字超出自己的框；
  - 被省略号截断的文字（只记录）；
  - 英法西文界面里还有没有中文（找漏翻）。
- **人工看图**：简中和法文的截图全部看过（法文最长）；繁中、英文、西文看自动检查标出来的页面。
- **结果**：
  - 只有 1 处横向溢出（法文，小镇兑换页底部的按钮被挤出屏幕）；
  - 英法西文里出现的中文都是玩家或运营填的内容（店名、活动标题、论坛帖子、区服名），没有漏翻；
  - 主要问题是英法西文的单复数，其次是几处排版。
- **对比图**：`visual-2026-10-05/`，`*-before.jpg` 是改前，`*-after.jpg` 是改后。

## 记下、这次没改的

- “名字×数量”中间没有空格（“Client ordinaire×4”）：全站约 90 处都这样写，是沿用中文的统一写法；法文习惯加空格。要改就全站一起改，单独排。
- 列表里的道具说明一行截断（商店、广场兑换）：点一下能展开全文，符合规范。
- 首页加成里的活动名、新闻里的店名是运营和玩家填的中文，不归界面管。
- 自动检查这轮只看了玩家页面，后台页面没有截图。

## 规范补充

已写进 [视觉规范.md](视觉规范.md)：
- 一排里有下拉框或输入框再加按钮时，输入框用 `.dt-shrink`，按钮 `flex-shrink-0`；
- 超过四列的数值表在手机上转置（每项一行）；
- 剩余时间一天以上写天和小时；
- 英法西文案里“数字 + 名词”一律用 `plEn` / `plFr` / `plEs`，不写“(s)”。
