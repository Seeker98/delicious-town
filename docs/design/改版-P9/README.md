## 和设计图不一样的地方

- **顶栏**：设计图里游戏页顶栏只有返回、标题和余额胶囊；实际顶栏还有原来的时间、邮件和“我”，余额胶囊放在时间前面。
- **神秘礼券的图**：设计图画的是黄色票券；实际用 P1 图库里已有的神秘礼券图（粉色票券带星），全站一致。
- **玩法面板**：设计图标题左边有游戏大图；实际面板标题是统一的一行字（“猜酒杯 · 玩法”），和其他面板一致。
- **英法西的雯姐按钮**：外文“聊天 · 送礼券”太长，把台词挤成一窄条，外文只写“聊天”。
- **厨塔一行**：今天打满的一层，右边写短标签“今天累了”（设计图是“他今天累了”）；守护者有男有女（问题记录 230），面板里写“今天还能挑战某某”“对手厨力”，不写“他”。
- **统计块**：厨塔顶上三块沿用 P5 的统计块（大数字在上、小字在下），设计图是小字在上。
- **魔鬼辣杯**：默认选中第一档押得起的押注（设计图示例选的是 5 张）。
- **赛厨榜**：不能挑战的行在名字下面用红字写原因（前 8 名的名次差限制、体力不够），设计图没画这一行。
- **奖池、我的统计、换蟹币、每周换榜**：都收成一行，点开从下面弹出，和设计图一致；设计图没画这几个面板，样式照 P8 的面板。
