## 和设计图不一样的地方

- **顶栏**：和 P9 一样，顶栏右边还有时间、邮件和“我”；“⋯”放在时间前面。
- **广场头图的天气胶囊**：天气数据里没有大类，用通用的天气图标，不按晴雨雪画；换天气面板也就不知道“现在是哪一类”，四类都能选（设计图把现在这一类灰掉）。
- **好友餐厅的操作块**：好友餐厅接口里没有“还能翻几格、还能换几次、菜园能偷几块”，这几格的副行写固定说明（“翻它的橱柜找食材”“2 个换它 1 个”）；好友对决照样写今天还能比几次。等级环只显示等级，不画对方的经验进度。
- **翻橱柜、换食材顶上的卡片**：左边画橱柜、万能食材，不画好友头像（这两页不读好友资料）。
- **好友动态**：和首页动态同一种行（时间 + 一句话），没有按事件画小图标。
- **改名、搬家面板**：不写“持有改名卡 / 搬家卡几张”（没有现成接口）；改名面板写现在叫什么，搬家合计框写要 1 张卡和大约多少银币。
- **扩油页**：没写“扩容后剩多少银币”。
- **论坛列表**：时间写月日时分，不写“1 小时前”。
- **镇长问答面板**：面板标题是“告诉镇长”，问题写在头像旁边。
- **教室开课面板**：没有残卷的菜灰掉（开课要用 1 张这道菜的残卷）；每道菜下面写持有残卷几张。
- **邮箱**：领过的邮件右边是绿色“已领取”小标签，删除在打开后的面板里；称号附件用“称”字代替图。
- **卡门的格子**：服务端新加了“每种神秘食材有几个”（只在卡门的页查），右上角写数量。
