说明

勾选 = 下架。下架的道具、食材保留定义（玩家手上已有的照常显示、能用能卖），但不再从任何途径产出：退出商店、随机奖励、食材池、交易所和 Wiki。保存前会按新名单构建一次：还被奖励、兑换、食谱等引用的，或代码里用到的，不能下架，会在上面列出原因，文件不写。

保存只写 packages/config/data/game/retired.json。要在游戏里生效：pnpm -F @dt/config build，再重启开发服务器。

来源、用途按配置和游戏里的规则函数算（默认区服数值）；划掉的来源是已下架的道具（例如下架礼包里的东西）。原版来源来自原版的获取途径表，只作参考。
